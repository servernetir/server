# صف اولویت و پذیرش

تطبیق ۸ نوامبر: [گزارش ادامه](continuation-2026-11-08.md) مقدم است. بسته‌های runtime قدیمی هنوز در نمونهٔ تولید فعال نیستند؛ CI و رندر ساختگی امروز موفق‌اند و پذیرش تصویری کاندید باز است. حذف سفارش‌های noindex از sitemap و اصلاح ادعاهای مشخص دو config در این PR آماده‌اند. منبع ecommerce تگ خرید به‌صورت صریح در workspace ذخیره شده، اما انتشار/دریافت Google هنوز تأیید نیست. دادهٔ Google/Bing/referral از اتصال جایگزین موجود قابل خواندن است؛ ردیف قدیمی «data gap» برای همین داده‌ها رفع شده و سنجش visibility پلتفرم‌ها همچنان مستقل است.

زمان‌ها برآورد مهندسی‌اند، نه تعهد زمان یا پیش‌بینی رشد. Done/Git با نصب و تأیید تولید متفاوت است.
