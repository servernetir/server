## تحلیل قابل بازتولید

`scripts/seo-growth-cycle/opportunities.py` دو export می‌گیرد: query/page و property daily. عبارت برند، مسیر خصوصی، URL خارجی، query string، ایمیل و شماره بلند حذف می‌شوند. خروجی نهایی [238 نامزد](evidence/opportunity-review-2026-11-03.json) شامل measured metrics، اقدام، اولویت و review_score است. امتیاز صرفاً ترتیب بررسی است.

چند URL برای یک عبارت، فقط علامت بازبینی است. مثلاً /gpu و /vps/gpu می‌توانند قصد «برنامه آماده GPU» و «VPS با کنترل سیستم‌عامل» را جدا کنند؛ پیش از ادغام باید محصول، لینک ورودی و query intent بررسی شود. حذف یا redirect خودکار انجام نشده است.
