# ServerNet: اجرای سئو و رشد ارگانیک

[اصلاح مستقل صفحهٔ ایران، احراز هویت و ایندکس](iran-marketing-2026-11-08.md): راهنمای عمومی فقط با عرضهٔ واقعی قابل ایندکس؛ دادهٔ پلن و سفارش همچنان پشت احراز هویت. این اصلاح با محدودهٔ مستقل ۹ مقصد و پذیرش ۱۳ GET در تولید تأیید شد؛ [رسید هر دو انتشار](production-release-2026-11-08.md).

آخرین وضعیت، ۸ نوامبر: [بستهٔ اصلی سئو در تولید نصب و تأیید شد](production-release-2026-11-08.md)؛ ۳۴ مقصد، ۱۱ نمای کامپایل‌شده و نسل PageCache برابر ۴۶۷۰→۴۶۷۱، پذیرش ۳۲ GET و مشاهدهٔ جداگانهٔ دسکتاپ/موبایل ثبت شدند. اصلاح مستقل ایران نیز با ۹ مقصد، دو نمای کامپایل‌شده، نسل ۴۶۹۱→۴۶۹۲ و پذیرش ۱۳ GET جداگانه تأیید شد. ادغام Git، نصب و تأیید تولید در رسید جدا شده‌اند.

جدول زیر، داده و آزمون تاریخی ۳ نوامبر است؛ ردیف انتشار به رسید تازه اشاره می‌کند. [گزارش ادامهٔ اجرا](continuation-2026-11-08.md) نیز سابقهٔ اختلاف Git/تولید و پیش‌نویس GTM را نگه می‌دارد. یکپارچه‌سازی کامل layout با PublicPageStyles و اثر عملکرد آن هنوز تأیید نشده‌اند.

همه اعداد عملکرد از Google Search Console و GA4 از طریق Windsor دریافت شدند؛ جمع کل گوگل از خروجی روزانه بدون بُعد عبارت/صفحه محاسبه و با رابط خود Search Console تطبیق داده شد. خروجی عبارت/صفحه جای کل دامنه نیست. رشد تاریخی نتیجه تغییرات امروز نیست.

صفحات ساعتی و GPU فارسی به‌ترتیب 584 و 517 کلیک دارند. مشکل اکثر صفحات هاست، جایگاه پایین است؛ بنابراین تغییر کور عنوان صفحات موفق انجام نشد. راهنمای خرید هاست، لینک ساعتی مشروط به عرضه واقعی، Service schema و حذف یک درخواست CSS مسدودکننده آماده‌اند. درآمد GA4 در خروجی‌ها صفر است و برای نسبت‌دادن درآمد به سئو قابل اتکا نیست.
