# نگهداری کش فایل

## رفتار

فایل‌استور Laravel فایل منقضی‌شده را هنگام خواندن همان کلید حذف می‌کند. کلیدهای نسل‌های قبلی PageCache ممکن است دیگر خوانده نشوند؛ در نتیجه پوشهٔ file cache بدون نگهداری رشد می‌کند. در پاک‌سازی ۲۰ نوامبر ۲۰۲۶، حدود ۸٫۵ GiB فایل منقضی‌شده حذف شد.

- فرمان `php artisan cache:prune-expired-file --dry-run` شمار و حجم ورودی‌های واجد شرایط را گزارش می‌دهد. فرمان بدون این گزینه، فایل‌هایی با زمان انقضای معتبر و سپری‌شده با مهلت پنج‌دقیقه‌ای را حذف می‌کند.
- فقط ساختار استاندارد دو سطحی SHA-1 در مسیر file cache بررسی می‌شود. قفل مستقل اجرا و قفل انحصاری فایل، تغییر هم‌زمان را کنترل می‌کنند. دادهٔ فعال، فایل بی‌فرمت، فایل متصل با hard link، session و upload حذف نمی‌شوند.
- زمان‌بندی در `routes/console.php` هر ساعت در دقیقهٔ ۳۷، با جلوگیری از هم‌پوشانی است. وضعیت حجم قبلی در فایل کوچک خصوصی زیر storage/app نگه داشته می‌شود.
- آستانه‌های پیش‌فرض هشدار مدیر بله: cache قبل از پاک‌سازی ۴۰۹۶ MiB، رشد/حجم حذف ۱۰۲۴ MiB و اشغال دیسک ۹۰٪. پیام در صورت تکرار حداکثر هر شش ساعت ارسال می‌شود. تنظیم از `CACHE_FILE_ALERT_SIZE_MB`، `CACHE_FILE_ALERT_GROWTH_MB` و `CACHE_FILE_ALERT_DISK_PERCENT`.
- رویدادهای created/deleted و تغییر واقعی مدل‌های عمومی نسل PageCache را عوض می‌کنند. ذخیرهٔ تکراری، updated_at و synced_at پلن به‌تنهایی نسل تازه ایجاد نمی‌کنند. تغییر قیمت/موجودی کماکان فوراً ابطال می‌کند.

## پذیرش و انتشار

در checkout ایزوله `php artisan test --filter=FileCacheMaintenanceTest` و `php artisan test --filter=PageCacheTest` اجرا شوند. فایل‌های production از روی manifest نصب شوند، `php artisan schedule:list` و dry-run بررسی شوند. تأیید نصب و نتیجهٔ اجرای واقعی جدا ثبت می‌شوند.
