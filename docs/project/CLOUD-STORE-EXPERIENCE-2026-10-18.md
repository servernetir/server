# بازطراحی فروشگاه سرور — ۱۸ اکتبر ۲۰۲۶

وضعیت: پیاده‌سازی، تست و پیش‌نمایش محلی آماده؛ هنوز روی تولید نصب نشده است. شاخه `codex/cloud-store-experience`، مقصد `develop`. مبنای نهایی با `c12b85d4` تطبیق دارد؛ کارت‌های نسخه، برنامه‌های آماده منطقه‌ای، لوگوها و چت تازهٔ منتشرشده حفظ شده‌اند. تغییرهای قبلی checkout اصلی دسکتاپ دست‌نخورده‌اند.

## رفتار جدید

- کشور و شهر یک مرحله‌اند؛ هر کد مکان/دیتاسنتر همان لینک مستقل و قیمت شروع سمت سرور را دارد. جست‌وجو فارسی/انگلیسی، نام اصلی شهر، کد و چند نام رایج کشور را می‌پذیرد.
- کره با جست‌وجو، فوکوس و مرور مقصد می‌چرخد. نام و مختصات، موقعیت تقریبی شهرند؛ مقصد فاقد شهر معتبر فقط مرکز کشور و توضیح صریح می‌گیرد. جست‌وجو یا مرور کره مقدار مکان سفارش را تغییر نمی‌دهد.
- صفحه از تمام عرض استفاده می‌کند؛ نوار مراحل افقی، خلاصه سفارش چسبان و نوار پرداخت موبایل حفظ شده‌اند. اسکرول صفحه با چرخ/لمس/صفحه‌کلید فعال است؛ نوار پیش‌فرض صفحه پنهان و نوار نتایج باریک و سفارشی است.
- انتخاب پلن یا نسخه قیمت را به‌روز می‌کند؛ حرکت بین مراحل با ادامه/ناوبری صریح است. عنوان مقصد فوکوس می‌گیرد و نوار مراحل پس از تغییر چیدمان زیر هدر قرار می‌گیرد؛ اسکرول به انتهای مرحله حذف شده است.
- خطای کلید SSH/IP اضافه مرحله مرور و تنظیمات پیشرفته را باز می‌کند. تغییر مکان، وضعیت ساعتی، دوره و ایمیج را حمل می‌کند. مسیر GPU همچنان سه مرحله و کلید جلوگیری از ثبت تکراری خودش را دارد.
- بدون JavaScript همه بخش‌ها قابل دسترسی‌اند، انتخاب کشور details بومی و انتخاب شهر لینک واقعی است. کره تصویر جایگزین دارد؛ reduced-motion و توقف رندر در حالت پنهان/ثابت رعایت می‌شود. هیچ API جغرافیایی بیرونی استفاده نمی‌شود.

## محدوده و قراردادها

فایل اصلی `website/resources/views/account/cloud-store.blade.php` به partial مکان و CSS/JS اختصاصی وصل می‌شود؛ layout پنل تنها یک stack برای CSS اختصاصی پس از `panel.css` گرفته است. متن‌ها در `lang/{fa,en,tr}/cloud-store.php` یکسان‌اند. React/TypeScript یا runtime جدید به اپ اضافه نشده؛ الگوی ارسالی کاربر با ساختار Blade موجود تطبیق یافته است.

نسبت به develop جاری، controller، مدل، سرویس، config، route، schema، موجودی، صورتحساب و provisioning هیچ diff ندارند. `priceMap`، `hourlyMap`، `imageMap`، `anchors`، `quoted_hourly_irt`، `gpu_request_key` و radio اصلی ایمیج حفظ شده‌اند. deduplication، کنترل هزینه/نرخ تازه، محدودیت منابع/منطقه برنامه و حفاظت سفارش پرداخت‌نشده همچنان سمت سرورند. تست‌های قدیمی تنها برای ساختار چهارمرحله‌ای و fixture معتبر Navasan به‌روز شدند؛ انتظارهای مالی تضعیف نشده‌اند.

## شواهد اجراشده

- PHP 8.4.26، SQLite حافظه‌ای و HTTP جعلی: **۱۸۵ تست / ۲۳۲۰ assertion، صفر failure/error**. گروه‌های خرید و نمایش CloudStore، شش رگرسیون تجربه، سه قرارداد برنامه منطقه‌ای، GPU/قیمت/ثبت تکراری/ظرفیت، اعتبار ساعتی، دوره LightNode، نرخ منطقه‌ای و رمز Windows پوشش دارند.
- Node 22 و jsdom 26: **۲۳ تست موفق**؛ ۱۰ کارت/منوی نسخه، ۷ جغرافیا، ۶ رفتار جست‌وجو/ناحیه/عدم تغییر سفارش/فوکوس میان‌بر. قرارداد standalone برنامه آروان نیز موفق است.
- ۳۶ خروجی واقعی Blade در fa/en/tr با مشتری و قیمت مصنوعی، ۴۱ assertion موفق؛ پیش‌نمایش فقط loopback و GET/HEAD است و POST سفارش را رد می‌کند.
- Chrome واقعی: فارسی/انگلیسی/ترکی، عرض‌های ۳۹۰/۷۶۸/۱۹۲۰، روشن/تیره، نبود سرریز افقی، مقصد Tokyo/Frankfurt، انتخاب نسخه Ubuntu و حفظ مرحله، فوکوس درست مرحله سیستم‌عامل، میان‌بر جست‌وجو و سه مرحله GPU بررسی شدند. خطای console در بازخوانی نهایی صفر بود.
- تصاویر و خروجی محلی در `output/cloud-store-experience-20261018/` checkout دسکتاپ‌اند؛ داده/قیمت آنها آزمایشی است. گزارش PHPUnit در `website/storage/framework/testing/cloud-store-verified.xml` است و در Git قرار نمی‌گیرد.

یک ممیزی گسترده‌تر پیش از تطبیق fixtureها، ۱۰۸ تست با ۲۸ failure و ۳ error داشت؛ عمده خطاها fixture قدیمی نرخ/قیمت در گروه‌های خارج این تغییر بودند. این suite به‌عنوان قبولی گزارش نمی‌شود. تست SQLite و پیش‌نمایش، خرید/تحویل واقعی یا پذیرش MariaDB تولید نیستند؛ تراکنش پولی یا ساخت VM برای این تغییر انجام نشده است.

## انتشار و بازگشت

انتشار بعدی باید فقط فایل‌های UI این تغییر را با manifest، hash قبل/بعد و backup خصوصی نصب کند؛ فایل‌های برنامه و document root عمومی cPanel جدا هستند. ابتدا assetهای جدید در هر دو مقصد لازم، سپس ترجمه/قالب/layout نصب شوند؛ `index.php`، کل app/public، تنظیمات یا کاتالوگ جایگزین نشوند. دستور build یا migration جدید لازم نیست. قواعد انتشار در [DEPLOYMENT](DEPLOYMENT.md) و وابستگی قبلی کارت‌ها در [رکورد کارت‌ها](CLOUD-STORE-IMAGE-CARDS-2026-10-18.md) ملاک‌اند.

بازگشت محدود: قالب/layout و ترجمه‌های همین انتشار با guard هش به backup خودشان برگردند؛ کارت‌های سیستم‌عامل و برنامه‌های فعلی حفظ شوند. assetهای جدید تا حذف آخرین ارجاع باقی بمانند. بازگرداندن کل اپ یا helper انتشار قبلی لازم نیست. rollback تولید اجرا/پذیرش نشده است.

هیچ ماشین، guest، route، NAT/firewall، DNS، Worker، proxy، cron، persistence یا state عامل شبکه تغییر نکرد؛ برای این تغییر وضعیت شبکهٔ تازه‌ای برای ثبت در `NETWORK-CURRENT.md` وجود ندارد.
