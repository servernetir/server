حالت پیش‌فرض قبلی `verified_balance_v1` همان کنترل تاریخ و exposure را نگه می‌دارد؛ مقدار ناشناخته fail-closed است. guard runtime وجود ثابت جدید Engine را می‌سنجد تا نصب ناقص یا bytecode قدیمی فروش را با سیاست ناهماهنگ باز نکند. هدر `X-Identity-Funding-Policy` نسخهٔ پشتیبانی Engine وب را نشان می‌دهد؛ فعال‌بودن حالت باید جدا از کنترل ثبت‌شده تأیید شود. مدیریت در هر سه زبان حالت واقعی و عدم بررسی مانده را توضیح می‌دهد.
