## تطبیق تولید و برنامهٔ انتشار

[Manifest شش فایل](seo-growth-followup-2026-10-25/release-manifest.csv) SHA-256 قبل و بعد را ثبت می‌کند. خواندن فایل با cPanel API و `update_html_document_encoding=0` انجام شد تا charset مصنوعی به HTML اضافه نشود.

سه فایل `config/blog.php`، `app/helpers.php` و `pages/blog-post.blade.php` با مبنای Git یکسان بودند. قالب‌های `hosting.blade.php` و `vps-hourly.blade.php` محافظ‌های مستقل `IranSalesVisibility` داشتند که در مبنای Git حاضر نبودند. نسخهٔ بسته با merge سه‌طرفه ساخته شد و همهٔ این محافظ‌ها را حفظ می‌کند؛ کپی کور فایل مخزن انجام نمی‌شود. partial تازه در تولید وجود نداشت.

نصب باید با قفل موجود، کنترل hash همهٔ مقصدها، پشتیبان خصوصی، بررسی دوباره پیش از نوشتن، جایگزینی محدود و hash نهایی انجام شود. وابستگی‌ها پیش از قالب مصرف‌کننده نصب شوند. config cache موجود باید پیش از هر نوشتن موجب توقف شود تا فعال‌سازی آن جدا بازبینی شود؛ cache عمومی و قفل‌ها flush نشوند. فعال‌سازی فقط OPcache فایل‌های هدف، compiled viewهای متناظر و نسل PageCache را شامل می‌شود. ابزار موقت باید POST، header محرمانه و انقضای کوتاه داشته باشد، token در URL نباشد و پس از کار حذف و ۴۰۴ آن تأیید شود.

این انتشار migration، seeder، کار مالی، ساخت یا حذف GPU/VPS و ارسال پیام لازم ندارد. قیمت و فهرست موجودی زنده تغییر نمی‌کند.

## رسید انتشار و پذیرش زنده

- هر شش hash پیش از نصب روی سرور درست بود؛ هر شش فایل stage با PHP8.4.27 و `short_open_tag=1` کامپایل/lint شدند. config cache وجود نداشت و OPcache وب `validate_timestamps=1` داشت.
- نصب تحت قفل، پشتیبان hash-verified و کنترل دوبارهٔ مقصد انجام شد. هر شش hash نهایی با manifest برابر بودند؛ محافظ‌های مستقل فروش ایران حفظ شدند.
- سه compiled view قبلی به‌صورت هدفمند باطل شدند؛ partial تازه cache قبلی نداشت. نسل PageCache جلو رفت و نگاشت جدید GPU در runtime واقعی بارگذاری شد. این یک تغییر cache است؛ «صفر نوشتن دیتابیس» ادعا نمی‌شود.
- [پذیرش عمومی۲۵صفحه](seo-growth-followup-2026-10-25/public-acceptance.json): همه۲۰۰، یکH1، زبان و self-canonical درست و JSON-LD قابل parse. هر۹مقاله، هر دو جایگاه محصول درست را داشتند؛ n8n متن استعلام داشت. کنترل دوره در n8n/GPU VM سه زبان حذف و در Python سه زبان حفظ شد. راهنمای Linux و مقصدهای محلی در هر سه صفحهٔ ساعتی حاضر بودند.
- در مرورگر، بخش جدید فارسی و anchor آن روی سایت باز شد؛ عنوان زیر هدر باقی ماند، چیدمان دو ستونه درست بود و در viewport۱۳۶۳پیکسل، عرض سند۱۳۴۸پیکسل بود؛ overflow افقی مشاهده نشد. این شاهد دسکتاپ است و جای تست دستگاه موبایل یا Web Vitals را نمی‌گیرد.
- ابزار موقت انتشار حذف شد و GET بعد از حذف۴۰۴ بود. هیچ کلید SSH یا حساب تازه ساخته نشد. پشتیبان در `/home/servernetcloud/seo-growth-followup-20261025-c0276072daf8/backups/20261025T152532485450Z` خصوصی باقی است.
- بازگشت لازم نشد. [خلاصهٔ ماشینی پذیرش](seo-growth-followup-2026-10-25/validation-summary.json) شامل زمان و حدود واقعی این تحویل است. آزمون نصب/بازگشت محلی شش‌فایلی،۹تست installer و۶حالت محافظ gateway نیز پیش از نصب موفق بودند.

## پذیرش‌های باز

- مرورگر GTM به صفحهٔ ورود Google رسید؛ ورود حساب در این نشست موجود نیست. فایل import باید از export واقعی حساب ساخته شود، Detailed Changes دقیقاً۱۰افزودن و صفر تغییر/حذف داشته باشد، سپس Preview و دریافت پارامترها در GA4 DebugView بررسی شوند. آماده‌بودن بسته معادل انتشار یا دریافت رویداد نیست.
- Google URL Inspection و selected canonical، دریافت واقعی درآمد/اولین پرداخت یکتا، انتساب بین دامنهٔ اصلی و کنسول و تحویل واقعی هنوز تأیید نشده‌اند.
- راهنماهای ComfyUI/Jupyter منتشرند؛ این نشست خروجی واقعی GPU یا بازیابی checkpoint خارجی را مستقل بررسی نکرده است. خلاصهٔ یک گفتگوی دیگر دربارهٔ تست ComfyUI جای artifact قابل بررسی نیست؛ آزمایش هزینه‌دار تکراری ساخته نشد.
- [تشخیص افت بلاگ](SEO-BLOG-TRIAGE-2026-10-25.md) انجام شد: سه URL مربوط به VPN و Discord مجموعاً۱۰۷کلیک از دست داده‌اند و بقیه۲۸کلیک رشد کرده‌اند. دو عبارت فارسی۵۰از۵۶کلیک قبلی VPN ترکی را ساخته‌اند؛ انتخاب زبان/URL گوگل نیاز به بررسی دارد. بازنویسی مقاله و بازیابی ورودی انجام‌شده اعلام نمی‌شود.
- عنوان/محتوای ابزارها قبلاً منتشرند؛ قبولی موتور برش و clipboard به آزمون تعاملی مستقل مربوط است.
