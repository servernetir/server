## مسئله و تغییر

صفحهٔ Python راهنماهای نامرتبط از جمله دیسکورد پیشنهاد می‌کرد. صفحات Object و Block به مقالهٔ مقایسهٔ موجود لینک نداشتند. دو مقالهٔ فنی نیز نمونه‌های قدیمی یا ادعاهای تأییدنشده داشتند. این نوبت مسیر مرتبط میان مقاله و خدمت را اصلاح و متن همان URLها را در سه زبان بازبینی می‌کند.

[منابع و تصمیم‌های تحریریه](seo-growth-cycle-2026-10-25/content-sources.md).
- Python راهنماهای مرتبط DNS، تشخیص کندی و سنجش تجربهٔ کاربر می‌گیرد. Linux و WordPress به راهنمای ارتقای PHP، مقایسهٔ کنترل‌پنل و تشخیص کندی وصل می‌شوند. Object و Block به مقایسهٔ خودشان لینک می‌دهند. مقاله‌ها نیز در دو جایگاه موجود به محصول درست متصل‌اند. [رفتار و آزمون لینک‌ها](seo-growth-cycle-2026-10-25/technical-links.md).

- [پروتکل چرخه](SEO-GROWTH-CYCLE.md)، [صف کار](seo-growth-cycle-2026-10-25/backlog.json) و checker عمومی برای ادامهٔ کار اضافه شدند. زمان‌بندی ChatGPT واقعاً فعال شده است: شروع ۲۶ اکتبر ۲۰۲۶ ساعت۰۲:۰۰ تهران و تکرار هر شش ساعت؛ ساعت‌های۰۲،۰۸،۱۴،۲۰. این رسید، موفقیت اجراهای آینده را ثابت نمی‌کند.

## انتشار و بازگشت

فایل‌ها فقط با manifest دقیق و hash پیش/پس، snapshot خصوصی دو مقاله و شش ترجمه، بازبینی مستقل و قفل انتشار نصب می‌شوند. اختلاف‌های معتبر نسخهٔ تولید حفظ می‌شوند. اعمال CMS از command موجود، با snapshot مورد انتظار، تراکنش و کنترل حفظ metadata انجام می‌شود. بازگشت CMS پیش از بازگشت فایل منبع و فقط در نبود ویرایش جدیدتر مجاز است؛ cache مرتبط پس از بازگشت فعال می‌شود.

[Manifest شش فایل](seo-growth-cycle-2026-10-25/release-manifest.csv) شامل دو منبع JSON، helper، نگاشت بلاگ، قالب Storage و کنترلر sitemap است. کنترلر زنده، تغییرهای قبلی قیمت صفحهٔ اصلی و IranSalesVisibility داشت؛ فقط delta بخش sitemap با merge سه‌طرفه افزوده شد و آن تغییرها حفظ شدند. hash منبع Git و بستهٔ تولید در manifest جدا ثبت شده‌اند.

دسترسی Google به انتخاب مالک فعلاً معلق است؛ چرخه دوباره درخواست ورود یا CAPTCHA نمی‌کند. GTM/GA4، URL Inspection و نسبت‌دادن درآمد به سئو همچنان پذیرش جدا می‌خواهند. تغییرات قیمت، provisioning، پرداخت، زیرساخت و ارسال پیام بیرونی جزو این نوبت نیستند.

صف بعدی شامل اصلاح راهنماهای backup، Git deployment و staging است؛ اشکال نمونهٔ آموزشی به معنی وجود همان endpoint یا آسیب‌پذیری روی سایت نیست. همچنین پذیرش موبایل/ابزارها و راهنمای اختصاصی Python بر اساس قابلیت واقعی محصول باقی‌اند.
