# اتصال اجرایی MCP برای سوشیال هرمس — ۲۶ اکتبر ۲۰۲۶

**وضعیت: پیاده‌سازی و آزمون محلی؛ نصب سرور و انتشار واقعی انجام نشده است.** مبنای تغییر `d8a143fda0e49ddaa3f53c8f213135e27890162e` از develop است. این بسته ناظر Laravel، دانش HMAC و ماژول Operations زنده را تغییر نمی‌دهد.

مالک خواست هرمس روی Windows یا Linux فایل‌های Drive را بگیرد و برنامه سه پیج را خودش اجرا کند. بسته [infra/hermes-social](../../infra/hermes-social/README.md) یک MCP محلی با نه ابزار، دستور شیفت و منبع آموزشی فراهم می‌کند. مسیر پیشنهادی، کاربر غیرریشه `hermes` در VM اختصاصی۱۲۷ است؛ وضعیت زنده و نسخه نصب‌شده این ماشین در این تغییر دوباره سنجیده نشده است.

## رفتار پیاده‌شده

- پوشه مجاز Drive و زنجیره والدها بررسی می‌شوند؛ فایل خارج از پوشه، shortcut، فایل حذف‌شده یا محتوای متفاوت با SHA-256 مصوب مسدود است.
- تصویر PNG پس از کنترل اندازه/نسبت به JPEG واقعی تبدیل می‌شود و تنها همان دارایی مصوب با URL امضاشده یک‌ساعته در اختیار Meta قرار می‌گیرد. Drive عمومی نمی‌شود.
- مقصدهای ثابت FA/EN/TR و ID/username واقعی حساب قبل از ساخت و انتشار بررسی می‌شوند. صف SQLite پیش از POST نهایی قصد اجرا را ثبت می‌کند؛ timeout به انتشار مجدد تبدیل نمی‌شود. دریافت ID به‌تنهایی موفقیت نیست: مالکیت رسانه، متن و رسید بررسی می‌شوند.
- ابزار خواندن کامنت و یک پاسخ به کامنت ورودی روی رسانه تأییدشده وجود دارد. پاسخ مبهم تکرار نمی‌شود. ابزار ارسال دایرکت عمومی، فرمان shell یا خواندن آزاد فایل سیستم وجود ندارد.
- فایل توقف، سقف روزانه، پنجره انتشار، رسید قابل همگام‌سازی با فایل JSON مشخص Drive و نمونه timer کاربر لینوکس فراهم شده‌اند. نصب/فعال‌سازی timer انجام نشده است.

## داده کمپین و پذیرش محلی

از بسته موجود مالک، فهرست خصوصی ۶۳کار ساخته و جدا از مخزن عمومی نگه‌داری شد:۲۱پست آماده و۴۲استوری نیازمند استیکر بومی. Hash بسته برنامه:

`fbe5d92dc72a48b06e2e7f3eca9b4157eca1cff793bb38da52f3dc75974b3c6e`

۴۵تست با Python3.12، mcp1.30.0، HTTP ساختگی و SQLite موقت موفق‌اند. آزمون واقعی پروتکل stdio شامل initialize، فهرست نه ابزار، فراخوانی ابزار متوقف، خواندن منبع و دریافت prompt انجام شد. قطع ارتباط، crash، رقابت، توقف، سقف، تطبیق حساب، scope/hash فایل، تبدیل تصویر، قرارداد carousel/reel/story، تعلق کامنت و تکرارنشدن پاسخ آزموده شدند. پیش‌بررسی نصب صفر نوشتن داشت؛ آزمون اعمال bootstrap با محیط و subprocess ساختگی بود. decoding و تبدیل JPEG همه۸۱تصویر واقعی کمپین موفق بود. compileall، pip check و diff check نیز موفق‌اند.

آزمون زنده Google/Meta/S3، نصب MCP در هرمس فعلی، اجرای Windows و اجرای timer تولید انجام نشده‌اند. هیچ پست یا کامنتی در این آزمون‌ها ارسال نشد.

## دسترسی‌های باقی‌مانده

راهنمای کامل نصب و توقف در [README بسته](../../infra/hermes-social/README.md) است. برای فعال‌سازی، این موارد باید در محیط واقعی تکمیل شوند:

1. اتصال اجرایی به ترمینال VM۱۲۷ و تأیید نسخه/قابلیت MCP هرمس فعلی؛ نصب به کاربر اختصاصی، جدا از وب cPanel.
2. JSON خصوصی Google یا OAuth مستقل همان برنامه؛ دسترسی فقط به پوشه کمپین. برای service account، Viewer جهت دریافت فایل و Editor جهت جایگزینی یک فایل رسید موجود کافی است؛ domain-wide delegation نیاز نیست.
3. مجوز رسمی هر سه حساب حرفه‌ای Instagram، ID و توکن متناظر هر حساب، نسخه پشتیبانی‌شده Graph و مجوز انتشار؛ مجوز کامنت جداگانه. helper توکن را با ورودی مخفی می‌گیرد و هویت را بررسی می‌کند. توکن در چت، Git یا سند عمومی قرار نگیرد.
4. کلید محدود یک prefix ذخیره‌سازی موقت HTTPS قابل دریافت توسط Meta. اطلاعات اتصال در فایل خصوصی سرور باشد.
5. ادغام fragment MCP با حفظ تنظیمات موجود، مشاهده واقعی ابزارها، آزمون انتشار مصوب دارای رسید، سپس فعال‌سازی timer و سیاست پاسخ‌گویی. اتصال Google در ChatGPT و ورود Chrome جای این مجوزها نیستند.

استوری تعاملی، دایرکت، اتصال CMS/تقویم و تغییرات فنی سئو در این بسته پیاده نشده‌اند. timer انتشار به‌تنهایی چرخه پاسخ‌گویی LLM ایجاد نمی‌کند؛ هرمس باید از دستور شیفت در برنامه موجود خود استفاده کند. تمدید خودکار توکن Meta نیز هنوز پیاده نشده است. بودجه AI، cron مالی، شبکه، ماشین مشتری یا مجوزهای Operations تغییر نکردند.

برای بازگشت، اجرا را متوقف و فقط entry این MCP و timer خودش را غیرفعال کنید؛ journal و رسیدها حفظ شوند. بازگشت کد، پست واقعی را از اینستاگرام حذف نمی‌کند.
