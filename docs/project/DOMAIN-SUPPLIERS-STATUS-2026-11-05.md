## ادامهٔ کد

منبع PR #183 با develop فوق تطبیق داده شد. رابط، بارگذاری خودکار تکی، مرتب‌سازی و تست‌های جدید develop حفظ شدند. تغییرهای هم‌زمان زیرساخت/مالی و هاست جایگزین نشدند.

پنج ایراد بازبینی رفع شد:

1. probe تأمین‌کنندهٔ OpenProvider تنظیمات حساب را درخواست و ارز `data.settings.currency` را می‌خواند؛ ارزهای متعارض همچنان رد می‌شوند و اشتراک خواندن فقط در محدودهٔ جستجو باقی است.
2. سفارش سایت‌ساز هنگام استفادهٔ مجدد از دامنهٔ لغوشده، binding و شناسه‌های قدیمی را پاک و حساب quote جدید را ثبت می‌کند؛ وضعیت انتقال/تلاش قدیمی نیز ریست می‌شود.
3. جستجو کوتاه‌ترین دورهٔ مجاز پسوند را انتخاب و همان دوره را برای مقایسهٔ قیمت تمام حساب‌ها و checkout نگهداری می‌کند.
4. هویت مخاطب از تنظیمات قیمت/قابلیت‌ها مستقل شد؛ تغییر credential/environment همچنان دسترسی به handle قبلی را می‌بندد و نتیجهٔ نامعلوم دوباره ارسال نمی‌شود.
5. دستهٔ صریح پسوندها در حضور پسوند اصلی یک جای اضافهٔ محدود دارد؛ پسوند آخر حذف نمی‌شود.

تست‌های رفتاری برای هر پنج مورد اضافه شدند. feature و مجوزهای مالی پیش‌فرض خاموش‌اند. manifest قدیمی ۲ نوامبر **بستهٔ نصب فعلی نیست** و باید با موجودی تازهٔ تولید دوباره ساخته شود.

## مرز انتشار و ادامه

این تغییر منبع است؛ نصب تولید/اجرای دو migration، ثبت امن کلید موجود در سرورنت، پذیرش OT&E و فعال‌سازی فروش انجام نشده‌اند. هیچ خرید/تمدید/انتقال، تغییر DNS یا دادهٔ مشتری در این بررسی اجرا نشد. دریافت صرف HTTP 200 گواه موفقیت عملیات نیست.

ترتیب ادامه: ورود معتبر OT&E → ثبت امن حساب/کلید آزمایشی → تست ثبت/تمدید/مدیریت و تطبیق نتیجه → manifest تازه و backup/restore مستقل → نصب محدود و دو migration → probe و قیمت حساب‌های واقعی → فعال‌سازی حساب‌های پذیرفته‌شده. خرید آزمایشی تولید فقط با نام/مدت/سقف هزینهٔ مشخص است.

بازگشت کد در حالت feature خاموش با بازگرداندن فایل‌های همان انتشار انجام می‌شود. پس از عملیات واقعی، ابتدا dispatch تازه متوقف و journal/reconciliation همان حساب حفظ شود؛ rollback مخرب schema یا خرید مجدد از تأمین‌کنندهٔ دیگر مجاز نیست.

## اعتبارسنجی همین ادامه

PHP 8.4.27 موجود در runtime محلی پیدا و اکستنشن‌های اجباری از جمله sodium تأیید شدند؛ وابستگی‌های قفل‌شدهٔ checkout موجود به checkout ایزوله کپی شدند و هیچ env/config تولیدی وارد تست نشد. اجرای محلی با seccomp و منع IPv4/IPv6، ۱۰۵ تست/۶۷۷ بررسی مرتبط را موفق گذراند. lint تمام۱۶۰ فایل PHP غیرBladeِ متفاوت با کاندید تاریخی و `git diff --check` موفق بود.

اجرای CI اولیه روی `15d0019` هر۲۴۷ تست جدید را اجرا کرد و دو ایراد تست پیدا کرد: id یک مدل مصنوعی به‌علت mass-assignment تنظیم نشده بود، و assertion متنی قدیمی به `finally` پیاده‌سازی منسوخ بارگذاری دسته‌ای وابسته بود. fixture اصلاح شد؛ قرارداد HTML اولیه جدا بررسی می‌شود و پایان/خطا/توقف چرخنده را مجموعهٔ فعلی آزمون رفتاری JavaScript روی Blade واقعی می‌سنجد. این اصلاح‌ها محافظ عملیاتی را تغییر نمی‌دهند. نتیجهٔ CI نهایی باید از اجرای همین head خوانده شود و اعداد تاریخی جای آن نیستند.
