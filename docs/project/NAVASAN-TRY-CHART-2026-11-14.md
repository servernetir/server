## منبع و رفتار

نرخ حوالهٔ لیر در جدول زندهٔ نوسان از محدودهٔ اعتبارسنجی لیر خارج بود. نرخ دلار/یورو/تتر تغییر منبع ندارند. فقط وقتی TRY حواله رد شود، سری عددی OHLC اسکناس لیر از `https://www.navasan.net/item_sell.php` با `item=try` و قرارداد درخواست عمومی خود صفحهٔ `dayRates.php?item=try` خوانده می‌شود. دریافت آزمایشی واقعی، سری تاریخ‌دار با قیمت پایانی سازگار با اسکناس لیر داد؛ HTML اولیهٔ صفحه اعداد placeholder دارد و هیچ‌گاه منبع قیمت نیست. JavaScript خارجی اجرا نمی‌شود.

ورودی باید JSON لیستی از نقاط شش‌عضوی `[id, epoch_seconds, open, high, low, close]` با زمان صعودی باشد؛ آخرین کندل باید تازه، قیمت‌ها صحیح و دارای حدود و OHLC سازگار باشند. سقف تازگی۴۸ساعت و محافظ تاریخ آینده/منشأ و واحد تومان حفظ می‌شود. قیمت پایانی همان کندل استفاده می‌شود؛ نه تقسیم حدسی نرخ حواله، نه ثبت نرخ ثابت. زمان شروع کندل، حد محافظه‌کارانهٔ تازگی است و در مدیر به همین نام نمایش داده می‌شود، نه به‌عنوان زمان آخرین معامله.

ردیف جایگزین با `source_item=try`، `source_kind=cash_daily_chart` و URL دقیق منبع ثبت می‌شود. نرخ ردشده، نامعلوم یا نامعتبر منتشر نمی‌شود. دریافت TRY پیش از فاز آماده‌سازی/انتشار هماهنگ FX و کاتالوگ است؛ شکست آن سه نرخ لازم را مسدود نمی‌کند. خواندن نرخ هیچ درخواست شبکه‌ای تازه نمی‌زند و fallback تاریخ را تمدید نمی‌کند.
