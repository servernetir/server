# دریافت خودکار لیر از نمودار نوسان —۱۴نوامبر۲۰۲۶

مبنای تغییر: `c66afbaf348599537944f69b9fb6c8f1930f0ad5` از develop. مالک دریافت همیشگی از نوسان را خواسته است؛ نرخ دستی درج نمی‌شود.

## منبع و رفتار

نرخ حوالهٔ لیر در جدول زندهٔ نوسان از محدودهٔ اعتبارسنجی لیر خارج بود. نرخ دلار/یورو/تتر تغییر منبع ندارند. فقط وقتی TRY حواله رد شود، سری عددی OHLC اسکناس لیر از `https://www.navasan.net/item_sell.php` با `item=try` و قرارداد درخواست عمومی خود صفحهٔ `dayRates.php?item=try` خوانده می‌شود. دریافت آزمایشی واقعی، سری تاریخ‌دار با قیمت پایانی سازگار با اسکناس لیر داد؛ HTML اولیهٔ صفحه اعداد placeholder دارد و هیچ‌گاه منبع قیمت نیست. JavaScript خارجی اجرا نمی‌شود.

ورودی باید JSON لیستی از نقاط شش‌عضوی `[id, epoch_seconds, open, high, low, close]` با زمان صعودی باشد؛ آخرین کندل باید تازه، قیمت‌ها صحیح و دارای حدود و OHLC سازگار باشند. سقف تازگی۴۸ساعت و محافظ تاریخ آینده/منشأ و واحد تومان حفظ می‌شود. قیمت پایانی همان کندل استفاده می‌شود؛ نه تقسیم حدسی نرخ حواله، نه ثبت نرخ ثابت. زمان شروع کندل، حد محافظه‌کارانهٔ تازگی است و در مدیر به همین نام نمایش داده می‌شود، نه به‌عنوان زمان آخرین معامله.

ردیف جایگزین با `source_item=try`، `source_kind=cash_daily_chart` و URL دقیق منبع ثبت می‌شود. نرخ ردشده، نامعلوم یا نامعتبر منتشر نمی‌شود. دریافت TRY پیش از فاز آماده‌سازی/انتشار هماهنگ FX و کاتالوگ است؛ شکست آن سه نرخ لازم را مسدود نمی‌کند. خواندن نرخ هیچ درخواست شبکه‌ای تازه نمی‌زند و fallback تاریخ را تمدید نمی‌کند.

## آزمون

PHP۸٫۴٫۲۷، SQLite، checkout ایزوله و HTTP ساختگی:۱۲۴تست/۱۴۵۸بررسی موفق؛ شامل انتشار هماهنگ، URL/ارز درست، رد تاریخ کهنه/آینده، مقدار اعشاری و واحد/منشأ نادرست و سری نامرتب. شکست baseline دامنهٔ گزارش قبلی از فیلتر مرتبط حذف شده و همچنان جدا ثبت است؛ MariaDB و خرید واقعی اجرا نشده‌اند. نصب/پذیرش تولید هنوز جدا بررسی می‌شود.

## LightNode

کلید Running موجود از صفحهٔ رسمی در تنظیمات رمزگذاری‌شدهٔ سرورنت دوباره ثبت شد؛ API رسمی مناطق همچنانHTTP401 داد. قالب هدر با مستند رسمی `apidoc.lightnode.com/7389921m0` سازگار است. درخواست جدیدِ ازقبلثبت‌شده در Applying است؛ طبق مستند رسمی، صدور کلید جدید به تأیید LightNode نیاز دارد. راز یا شناسهٔ کلید در این گزارش نیست؛ ساخت درخواست تکراری یا حذف کلید موجود انجام نشد.

## نصب و بازگشت

بسته فقط شامل ExchangeRate و نمای نرخ‌گذاری مدیر است؛ اسکریپت انتشار جدا، قفل، کنترل هش، حفظ تغییر هم‌زمان و پشتیبان خصوصی دارد. migration، راز، فاکتور و سرویس مشتری تغییر مستقیم نمی‌کنند. بازگشت فایل‌ها از پشتیبان همین انتشار با کنترل هش و کامپایل مجدد فقط نمای مربوط انجام شود. بازگشت کد، نرخ/قیمت منتشرشده را خودکار برنمی‌گرداند؛ قیمت‌ها فقط از مسیر رسمی هماهنگ دوباره منتشر می‌شوند.
