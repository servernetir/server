# لوگوی برنامه‌های آماده — ۱۸ اکتبر ۲۰۲۶

وضعیت: منتشر و روی فروشگاه زنده تأیید شد. شاخه `codex/ready-app-logos-20261018`، ادامهٔ تغییر آماده‌سازی کاتالوگ.

## محدوده و تغییر

ممیزی SELECT-only کاتالوگ فعال ۷۲ خانوادهٔ برنامه را نشان داد. لوگوی عمومی برای برنامه‌های تازهٔ ایران و بسیاری از برنامه‌های سایر ارائه‌دهندگان از نبود asset اختصاصی و نگاشت ناقص می‌آمد. به‌علاوه، JS برخی لوگوهای انتخاب‌شده توسط مدل را با مسیر قدیمی سیستم‌عامل جایگزین می‌کرد.

- ۷۲ asset خودمیزبان در `website/public/assets/apps/`، با canvas و فاصلهٔ یکسان و زمینهٔ خوانا در روشن/تیره؛ لوگوی Plesk و Uptime Kuma از نظر کنتراست اصلاح شد.
- `CloudImage::APP_LOGOS` برای خانواده‌های موجود اضافه شد. `logo()` برای برنامه‌های شناخته‌شده مسیر اختصاصی apps و برای خانوادهٔ آینده همان fallback امن قبلی را می‌دهد. لوگوی سیستم‌عامل‌ها تغییر نکرد.
- انتخابگر JS مسیر اختصاصی مدل را حفظ می‌کند؛ نشان خلاصهٔ سفارش هم همان مسیر است. تصاویر کارت بارگذاری lazy دارند. payload اصلی سفارش و انتخاب نسخه تغییر نکرد.
- قالب اختصاصی GPU به جای نشان عمومی کتاب/ربات/نمودار از لوگوی Jupyter/ComfyUI/Ollama استفاده می‌کند. تصمیم موجود دربارهٔ توقف فروش این برنامه‌ها تغییر نکرد.
- LAMP و LEMP برند مستقل واحدی ندارند؛ از ترکیب نشان‌های Linux، Apache یا NGINX، MySQL و PHP استفاده شد. لوگوی یک محصول دیگر به‌جای این پشته‌ها قرار نگرفت.

## منابع و قالب فایل‌ها

منشأ هر نشان در `website/public/assets/apps/sources.json` ثبت است. Dashboard Icons به commit `6d31345986eba2067a63eb41c1a5a87d4e8e850a` و Simple Icons به `16.35.0` مقیدند؛ licenseهای مجموعه‌ها همراه فایل‌ها نگهداری/منتشر شدند. نشان‌های Fastpanel، TinyCP، Keitaro، ispmanager، Dokku، Hikka و TorrServer از وب‌سایت یا repository خود پروژه گرفته شدند. نام و نشان‌ها برای شناسایی همان نرم‌افزارند و مالکیت برند تغییر نمی‌کند.

چهار نشان raster اصلی بدون درخواست خارجی داخل wrapper SVG قرار دارند؛ TinyCP از ICO به PNG تبدیل شد. باقی نشان‌ها vector هستند. SVGها از نظر XML و محتوای فعال/منبع خارجی بررسی شدند؛ script، foreignObject، handler رویداد و URL خارجی در خروجی نیست. ۷۲ لوگو در یک gallery محلی جداگانه دیده و همگی بارگذاری شدند. gallery و server محلی بررسی، محصول منتشرشده نیستند و در Git قرار نگرفتند.

منابع مرجع: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons)، [Simple Icons](https://github.com/simple-icons/simple-icons)، و URLهای دقیق در manifest منشأ. تصویرهای نهایی بررسی در `output/app-logos-20261018/` محلی‌اند و در Git نیستند.

## انتشار و اعتبارسنجی

میزبان متاثر فقط cPanel موجود بود؛ ریشهٔ برنامه `/home/servernetcloud/servernet_app` و document root مستقل `/home/servernetcloud/public_html`. ۷۵ فایل asset/metadata/license در هر ریشه و چهار مسیر کد (مدل، Blade و JS در دو ریشه)، جمعاً ۱۵۴ مسیر، با precondition دقیق و backup خصوصی نصب شدند. CSS موجود بازنویسی نشد. assetها پیش از کدی که آن‌ها را نمایش می‌دهد نصب شدند. helper یک‌بارمصرف، drift guard و rollback دارد.

پوشهٔ خصوصی `/home/servernetcloud/app-logos-20261018/release` شامل manifest، فایل‌های مرحله‌بندی، backupهای کد قبلی، receipt نصب، helper و بررسی نگاشت/Blade است؛ دسترسی پوشه محدود و خارج public root است. هیچ credential یا دادهٔ مشتری داخل بسته یا مستندات قرار نگرفت. reset رسمی وب HTTP 200 و `opcache_reset=true` داد؛ config/route/view/application cache طبق endpoint موجود پاک شدند.

- ۱۰ تست رفتاری موجود JS موفق؛ syntax JS و diff whitespace بررسی شد.
- مدل مرحله‌بندی‌شده بدون bootstrap برنامه/DB برای هر ۷۲ خانواده مسیر صحیح داد؛ fallback برنامهٔ ناشناخته و لوگوی Ubuntu هم صحیح ماندند.
- PHP lint مدل، compile قالب Blade و PHP lint خروجی compile موفق بودند.
- hash نهایی هر۱۵۴مسیر با manifest برابر بود. GET عمومی هر۷۲SVG روی console با HTTP200، `image/svg+xml` و SHA برابر فایل منتشرشده تأیید شد.
- مرورگر واقعی: ۱۲ کارت آلمان و ۹ کارت ایران با نشان اختصاصی و بارگذاری موفق؛ انتخاب Docker همان radio قبلی و لوگوی اختصاصی خلاصه را نشان داد؛ حالت روشن/تیره بررسی و رنگ اولیه بازگردانده شد؛ خطای بارگذاری در کارت‌های بررسی‌شده صفر.
- صفحهٔ GPU همچنان برنامه‌ها را به‌دلیل توقف فروش قبلی پنهان می‌کند؛ برای گرفتن screenshot لوگو، gate فروش دور زده نشد. اصلاح قالب GPU با compile و نگاشت asset تأیید شد، نه رندر کارت قابل سفارشِ متوقف‌شده.

هیچ DB write، تغییر کاتالوگ/قیمت/پلن/موجودی، درخواست GPU، خرید، پرداخت، boot/reinstall یا تغییر سرویس مشتری انجام نشد. DNS، route، NAT، firewall، cron و منابع state عامل‌های شبکه ثابت‌اند. پایداری تغییر از فایل‌های برنامه/public root و شاخهٔ Git است؛ سرویس/تنظیم شبکهٔ تازه لازم نیست.

## بازگشت

ابتدا hash و receipt خصوصی را با وضعیت زنده تطبیق دهید؛ helper را دوباره کورکورانه prepare/apply نکنید. `python3 /home/servernetcloud/app-logos-20261018/release/deploy.py --rollback` فقط در صورت برابر بودن hash همهٔ مسیرها با نسخهٔ نصب‌شده ادامه می‌دهد. کد قبلی را پیش از حذف assetهای تازه بازمی‌گرداند، سپس reset وب رسمی را اجرا می‌کند؛ فایل‌های تازه فقط تکی و با hash guard حذف می‌شوند، پوشهٔ دیگری پاک نمی‌شود. تغییر هم‌زمان، بازگشت خودکار را متوقف می‌کند و باید دستی reconcile شود. rollback این اصلاح به کاتالوگ، سفارش یا توقف فروش دست نمی‌زند.
