## یافته‌ها و اصلاح

- `/cloud` در دو درخواست مستقل پس از ۲۵ و ۳۰ ثانیه بدون دریافت بایت timeout شد؛ ناوبری مرورگر نیز به مقصد نرسید. `CloudDominance::prune` در کاتالوگ سراسری مقایسهٔ درجه‌دو انجام می‌داد. کاندیدها اکنون ابتدا با شهر canonical گروه‌بندی می‌شوند؛ همان predicate، همان ترتیب خروجی و همان محاسبات قیمت/قرارداد حفظ شده‌اند.
- کارت ثبت دامنهٔ خانه، قیمت دورهٔ ثبت را با پسوند ماهانه نشان می‌داد. اکنون TLD و دورهٔ واقعی `min_years` نمایش داده می‌شوند. مبلغ تغییر نمی‌کند.
- قیمت ناموجود به‌شکل «شروع از — / ماهانه» دیده می‌شد؛ از متن ترجمه‌شدهٔ موجود تماس برای قیمت استفاده می‌شود.
- پلن‌های هم‌نام صفحهٔ اصلی موقعیت نداشتند و لینک انتخاب، موقعیت/پلن را از دست می‌داد. نام موقعیت محلی و query موجودِ پشتیبانی‌شدهٔ فروشگاه اضافه شد. پیشنهاد عمومی تخفیف سالانه از همین بخش حذف شد، چون همهٔ قراردادها این روش را ندارند؛ موتور صورتحساب تغییر نکرد.
- منوی موبایل فقط از نظر ظاهری باز می‌شد؛ focus و محتوای زمینه برای صفحه‌خوان/کیبورد مدیریت نمی‌شد. کشو اکنون modal با focus داخلی، حبس Tab، Escape و بازیابی focus/scroll است. بخش‌های بسته inert می‌شوند؛ خروج به عرض دسکتاپ قفل زمینه را آزاد می‌کند.

۲۵ صفحهٔ نمونه پاسخ۲۰۰، یک H1، canonical خود، چهار alternate واقعی و JSON-LD داشتند؛ مشکل HTTP مهم همین `/cloud` بود. CSS سریع دبی/مانیلا در نسخهٔ فعلی به‌علت اختلاف dependencyها با manifest از hash guard عبور نمی‌کند؛ hashها بدون بازسازی/بررسی دوباره تأیید نشدند. گزارش روزانهٔ GSC و مسئلهٔ LCP گروهی در [گزارش روزانه](../../SEO-DAILY-2026-10-28.md) ثبت است.

## پذیرش تولید و اصلاح تکمیلی

نصب اولیه در ۰۸:۴۶:۳۷ UTC، معادل ۱۲:۱۶:۳۷ تهران، شامل ۹ فایل app و نسخهٔ مستقل asset عمومی بود. پشتیبان خصوصی با شناسهٔ `.ux-release-20261028-0833`، before/after hash و ادغام محدود ثبت شد. دو تعارض home فقط در نمایش سالانهٔ همان بخش حل شدند؛ محدودیت‌های فروش ایران، quote عمومی، عرض header کنسول و دو نسخهٔ مستقل fallback چت حفظ شدند. asset عمومی با snapshot خودش جداگانه ادغام شد، نه از روی نسخهٔ متفاوت app/public. هیچ دسترسی تازه، migration، تغییر مالی یا purge کلی cache اجرا نشد.

سنجش روی دادهٔ واقعی نشان داد گروه‌بندی شهر به‌تنهایی کافی نیست: با ۸۷۸ عرضه، ساخت rows هنوز۱۹٫۶۴۳ثانیه بود. در اصلاح دوم، شرط‌های ارزان و ناممکن‌بودن تسلط قبل از حل قرارداد گران بررسی شدند؛ همان۸۲۱ردیف در۳٫۳۵ثانیه ساخته شد. آزمون مرجع از کپی مستقل predicate قدیمی استفاده می‌کند، نه تابع جدید. رندر نهایی cloud در سه زبان۷٫۳۸–۷٫۹۷ثانیه در CLI بود. HTTP عمومی پس از نصب۲۰۰ شد؛ دو درخواست از این کلاینت۸٫۵۹ و۱۴٫۸۴ثانیه زمان کل داشتند (دومی با query و بدون cache صفحه). صفحه دیگر در نمونهٔ قبل/بعد timeout نشد، اما سرعت سرد هنوز مطلوب نیست و هیچ ادعای LCP زیر۲٫۵ثانیه یا بهبود پایدار رتبه نمی‌شود.

پذیرش زنده، race فوکوس منو هنگام انیمیشن visibility را آشکار کرد؛ retry محافظت‌شده روی frame بعد و پایان transition اضافه شد. پس از انتشار تکمیلی، focus روی `drawer-close`، Tab داخل کشو و بازگشت Escape به `hamburger` در مرورگر واقعی تأیید شد؛ AX فقط محتوای کشو را نمایش داد. ظاهر قیمت/موقعیت پلن در موبایل بازخوانی شد؛ CSS و فونت تغییر نکردند. خانه fa/en/tr، ساعتی، GPU و دامنه fa/en/tr پاسخ۲۰۰ و markup تازه داشتند؛ asset عمومی هر دو marker فوکوس و محافظ morph چت را داشت. ۹ رندر staged خانه/کاتالوگ/دامنه در سه زبان با جلوگیری از SQL write و صفر write پذیرفته شدند.

حین پایان پذیرش، توسعه‌دهندهٔ دیگری هشت کلید `choice_*` را به هر فایل ترجمه اضافه کرد. کنترل hash این تغییر را متوقف/گزارش کرد؛ diff فقط همین افزوده‌ها بود و کلید خودمان حفظ شده بود. آن فایل‌ها بازنویسی نشدند. رسید، hash زمان نصب و hash جاری جدا دارد. **rollback ترجمه‌ها اکنون فقط حذف کلید `hp_domain_plans_sub` با گارد و حفظ افزوده‌های همکار است؛ restore کامل snapshot قدیمی مجاز نیست.** برای سایر فایل‌ها نیز قبل از restore، نبود تغییر بعدی باید تأیید شود.

نتیجهٔ آزمون نهایی: ۸۲ تست PHP /۳۸۱ assertion مرتبط، ۱۵ تست JS و lint موفق. CI روی PR۱۴۰ و۱۴۱ موفق بود؛ برای PR۱۴۲، check ثبت‌شده‌ای وجود نداشت و تست رفتاری محلی/مرورگر اجرا شد. شکست‌های baseline ذکرشده همچنان جدا ثبت‌اند. خرید/پرداخت واقعی و GA4 conversion امروز آزموده نشدند؛ موفقیت آنها از۲۰۰ یا عدم تغییر مسیر نتیجه‌گیری نمی‌شود.
