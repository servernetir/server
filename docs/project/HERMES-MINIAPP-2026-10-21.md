# مینی‌اپ Hermes، پایش خطا و بررسی ساعتی تیکت

مبنای حفظ کد: `servernetir/server`، شاخهٔ `develop`، کامیت `3e7bd7355e0cbe86702225c824fecf98ad257843`. اپ فعال `website/` است. این بسته کد نهایی Laravel و اصلاح محدود Worker دامنهٔ بله را برای بازبینی و حفظ در Git آماده می‌کند؛ تنظیمات و دادهٔ خصوصی تولید در آن نیستند. ثبت Git، نصب فایل و پذیرش تولید سه وضعیت جدا هستند؛ رسید انتشار خصوصی، وضعیت محیط را مشخص می‌کند.

## دامنهٔ کد

کنترلر، احراز مالک بله، ذخیرهٔ رمزنگاری‌شدهٔ گفتگو/حافظه و relay از برداشت تازهٔ نسخهٔ زنده حفظ شده‌اند. چت در مینی‌اپ می‌ماند و درخواست نامطمئن برای گرفتن پاسخ دوباره ارسال نمی‌شود؛ خواندن وضعیت، نتیجهٔ ذخیره‌شده را تطبیق می‌دهد. تغییر افزوده، سه وزن فونت موجود را با مسیر محدود سرو می‌کند، پنل وضعیت بررسی ساعتی و پنج خطای اخیر را می‌افزاید و خطاهای HTML/JSON نامعتبر را با پیام قابل‌فهم و شناسهٔ پیگیری نمایش می‌دهد.

APIهای تازهٔ پایش در `website/routes/hermes-monitor.php` هستند. احراز امضای بله یا نشست رمزنگاری‌شدهٔ مالک، بررسی اتصال فعلی مالک و محدودیت درخواست حفظ می‌شود. معافیت CSRF فقط برای همان APIهای مشخص با احراز مستقل است؛ معافیت فراگیر یا احراز از کوکی اضافه نشده است. `HermesMiniAppAudit` نتیجهٔ APIهای موجود را مشاهده می‌کند و محتوای پاسخ یا منطق اجرای آن‌ها را عوض نمی‌کند.

گزارش خطا فقط metadata محدود و گروه‌بندی‌شده نگه می‌دارد: زمان، کد شناخته‌شده، عملیات، وضعیت، شمارنده و شناسهٔ پیگیری. متن خام استثنا، HTML، کلید، هدر، URL/query، متن گفتگو و پیش‌نویس به API گزارش خطا راه نمی‌یابند. فایل‌ها در مسیر خصوصی خارج webroot با دسترسی محدود می‌مانند.

بررسی ساعتی از فرمان `hermes:support-review` و scheduler موجود استفاده می‌کند؛ cron دوم ندارد. شروع پردازش از زمان فعال‌سازی است، نه بازپخش تمام تیکت‌های قبلی. پیش‌فرض پنج و حداکثر ده بررسی در هر نوبت، قفل هم‌پوشانی، بررسی دوبارهٔ مالکیت و آخرین پیام، درج اتمی پاسخ و ثبت پایدار جلوگیری از تکرار دارد. تنها سؤال روشن‌ساز فارسیِ مجاز برای تیکت فارسیِ کم‌خطر خودکار ارسال می‌شود. موارد مالی، رمز/کلید، امنیت، زیرساخت مشترک و تغییر وضعیت برای بازبینی می‌مانند. این قابلیت فرمان مشتری اجرا نمی‌کند و زیرساخت را خودکار تعمیر نمی‌کند.

## حفظ تغییرهای هم‌زمان

فایل‌های `website/routes/web.php` و `console.php` از همان SHA مبنای Git گرفته شدند و فقط require دو فایل Hermes و زمان‌بندی ساعتی به آن‌ها افزوده شد؛ کل فایل‌های مسیر تولید روی Git کپی نشده‌اند. در `routes/hermes.php` تنها middleware پایش به گروه موجود افزوده می‌شود. در `AdminBaleRouter` اختلاف نسخهٔ زنده با Git دقیقاً شش خط برای فرستادن فرمان یا پاسخ Hermes به relay است؛ جایگاه بررسی مالک و جلوگیری از تکرار حفظ شده است. کنترلر، احراز، store و relay زنده با نسخهٔ آزمایشی قدیمی جایگزین نشده‌اند. ماژول صف Python و installer آزمایشی آن در این بسته نیستند؛ هیچ تغییر یا restart برای ingress خصوصی VM از این بسته انجام نمی‌شود.

## آزمون و مرز پذیرش

آزمون‌های مستقل در `website/tests/Standalone/Hermes/` قرار دارند. مجموعهٔ Python انتشار، manifest و hash guard، patch محدود، rollback، تغییر هم‌زمان، مسیر خصوصی، symlink و حفظ handlerهای چت/حافظه را روی فایل‌های موقت می‌سنجد. آزمون‌های PHP با منابع ساختگی، مجوز مالک، عادی‌سازی خطا، حذف دادهٔ حساس، پایش وضعیت، طبقه‌بندی ریسک، جلوگیری از تکرار، تازگی پیام، مالکیت، درج اتمی و تصمیم فعال‌سازی را می‌سنجند. آزمون مستقل جای آزمون کامل Laravel یا پذیرش واقعی ارسال/زمان‌بندی را نمی‌گیرد.

در محیط محلیِ آماده‌سازی، ۲۰ آزمون Python، ۱۲ آزمون Node پنل و ۱۷ آزمون Node Worker روی مسیرهای نهایی این بسته موفق شدند. آزمون پنل همان view را در سه زبان با DOM ساختگی می‌سنجد. آزمون Worker اختلاف دقیق شش ورودی، مقصد ثابت، هدرهای مجاز، حذف کوکی، متد/مسیر/سقف درخواست، خطای امن و رفتار قدیمی را با fetch ساختگی می‌سنجد؛ هیچ ترافیک شبکه‌ای ندارد. در runtime مجاز PHP، ۵۷ آزمون مستقل موفق شدند: پایش۱۵، audit۴، policy/state/processor۲۰، ارسال۱۰، draft۳ و فعال‌سازی۵؛ lint فایل‌های PHP مرتبط نیز با کد صفر تمام شد. این‌ها آزمون کامل Laravel یا ارسال واقعی به مشتری نیستند.

## رسید فعال‌سازی و مرز وضعیت تولید

بررسی ساعتی بومی در `2026-10-21T14:26:18Z` با cutoff برابر `1792592778` فعال شد. هر ۱۶ بررسی preflight موفق بود. دقیقاً یک cron موجود و یک زمان‌بندی ساعتی وجود دارد و executor دوم ساخته نشده است. اولین اجرای واقعی فرمان در `14:26:19Z`، `completed=true`، `scanned=0`، `failures=0`، `tracker_new=0` و `sent=0` ثبت کرد. این اجرای خالی، ارسال واقعی پاسخ یا پیشرفت نوبت طبیعی بعدی cron را اثبات نمی‌کند.

فونت، پنل وضعیت، API پایش و زمان‌بندی Laravel نصب شدند. مانع پاسخ عمومی مسیرهای تازهٔ `.ir` به allowlist دقیق Worker موجود رسید، نه احراز یا روت Laravel. کد `infra/cloudflare/servernet-ir-worker.mjs` فقط شش مسیر/متد مشخص را به همان شاخهٔ Hermes اضافه می‌کند: سه فونت با GET/HEAD، خطاها و automation با GET و client-errors با POST. مقصد ثابت، احراز اپ، فهرست هدرهای عبوری، حذف کوکی، کنترل متد و بقیهٔ redirectهای Worker عوض نمی‌شوند. نسخهٔ قبلی فعال در UI با پیشوند `f6558fed` و SHA-256 منبع `b650382905ed1ea3407d52f6b32b1089024b05e544c3d0edad0ae21d71a8f28a` ثبت شد. Worker جدید با نسخهٔ فعال/latest پیشوند `d4b5e0f8` منتشر و منبع پس از انتشار از UI دوباره خوانده شد؛ SHA-256 بایت‌های نهایی `e14da80f203acd094c434924cbd728aedfc014a5a1f4c8ef6bcd1e5b32f90f89` است و همین بایت‌ها در Git حفظ می‌شوند. تفاوت با فایل پیشنهادی `2c835d26c2212b3baa59bd327a56249194be331ef6ef7aff9a02ddb39a003c4d` فقط serialization پایان خط است؛ SHA-256 هر دو پس از تبدیل CRLF به LF برابر `5a1b6825aad61746a185623f9a139fbc52f3a1e50175bdf5092543f0d636c33a` است. شناسهٔ کامل نسخه‌ها از UI خوانده نشده است.

پذیرش عمومی `.ir`: هر سه فونت GET۲۰۰، `font/woff2` و امضای `wOF2` داشتند. درخواست بدون امضای مالک به errors و automation، پاسخ JSON برنامه با۴۰۳ داد؛ احراز دور زده نشد. در مینی‌اپ واقعیِ مالک، پنل فعال، زمان آخرین بررسی `17:56:19` تهران، شمار پاسخ صفر و پیش از probeهای بدون امضا خطایی نمایش داده نشد. پاسخ تست echo داخل همان پنل دیده شد و تاریخچه پس از بستن/بازکردن باقی ماند. این شواهد یک تعامل مالک را تأیید می‌کنند و به معنی تضمین تمام فرمان‌ها یا آزمون ارسال واقعی تیکت نیستند.

سه exception موقتِ تشخیصی حذف و چهار روت اصلی Worker حفظ شده‌اند؛ روت اصلی همچنان به Worker موجود وصل است. هیچ restart یا تغییر VM/ingress/n8n انجام نشد. ثبت Git این وضعیت را حفظ می‌کند و انتشار مجدد یا تغییر روت‌های دامنه را اجرا نمی‌کند.

شمارندهٔ تاریخی یا HTTP 200 به‌تنهایی گواه فعال‌سازی نیست. نشست واقعی بله، حفظ ماندگاری گفتگو، دریافت پاسخ داخل مینی‌اپ، فونت در webview، پیشرفت طبیعی scheduler و نتیجهٔ تیکت باید جداگانه پذیرفته شوند.

راهنمای ابزارهای انتشار خصوصی، preflight پیش‌فرض بدون تغییر تنظیمات، فعال‌سازی صریح، مرز ارسال و بازگشت در [infra/hermes/README](../../infra/hermes/README.md) آمده است. هیچ helper یا تستی در document root نصب نشود. پیش‌نیاز hash و قفل انتشار حفظ شود؛ برای بازگشت، تغییر جدیدتر تولید و پیام‌های ثبت‌شده بازنویسی نشوند.
