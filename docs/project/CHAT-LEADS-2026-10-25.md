## مسیر و ماندگاری

Workflow مستقل SJ5y9TXFybxdagPn هر پنج دقیقه جدول ذخیره‌شده را می‌خواند و با همان شناسه‌ها تطبیق می‌دهد. درخواست‌ها یک‌به‌یک و با فاصلهٔ یک ثانیه‌اند، Accept صریح JSON دارند و redirect دنبال نمی‌شود. در نتیجه credential روی redirect منتقل نمی‌شود و یک خطای HTTP به اجرای ناموفق قابل مشاهده در n8n تبدیل می‌شود. منبع قابل بازسازی و سه آزمون آن در relay/n8n/chat-leads-console.cjs و فایل test کنار آن است؛ خود workflow شامل کلید خام نیست و از credential رمزگذاری‌شدهٔ Header Auth محدود به دامنهٔ کنسول استفاده می‌کند.
