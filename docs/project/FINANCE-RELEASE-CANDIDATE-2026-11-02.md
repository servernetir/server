وضعیت: آماده‌سازی بستهٔ کاندید منبع؛ **نصب تولید و ثبت حساب واقعی هنوز تأیید نشده‌اند**. این سند رسید نصب نیست. مرجع محصول `190ff59cc1531399c7cdbd8b928b54d3c7727ae6` از develop است؛ تغییرهای این بسته فقط ابزار بسته‌بندی و همین مستندات‌اند.

## دامنه و منشأ

اتحاد فایل‌های محصول PR194، PR195 و PR201 دقیقاً ۲۶ منبع و ۲۸ مقصد دارد. دو CSS اختصاصی در `servernet_app/public/assets/css/` و `public_html/assets/css/` مقصد دارند؛ سایر منابع زیر `servernet_app/` هستند. مسیرهای دقیق در [scope.json](../../scripts/finance-release-20261102/scope.json) آمده‌اند. فایل‌های جدید بانک/سند مرتبط دو migration افزایشی جدا هستند؛ ترتیب هویت بانک سپس سند مرتبط حفظ می‌شود. سه Blade مدیریت تغییر کرده‌اند.

سورس مالی نسبت به نسخهٔ اصلاح‌شدهٔ PR201 تغییر نکرده است. آزمون محصول، اجرای تاریخی [41396096976](https://github.com/servernetir/server/actions/runs/41396096976) است: ۱۹۷ تست / ۱۵۰۴ assertion در هر کدام از SQLite و MariaDB و ۱۲ حالت Chromium. این نوبت همان تست‌ها دوباره اجرا نمی‌شوند؛ آزمون تازهٔ این تغییر، ساخت و اعتبارسنجی خود بسته است. [رسید اصلاحات](FINANCE-FUNDING-REVIEW-FIXES-2026-11-02.md) مرجع جزئیات محصول است.

## خروجی قابل بررسی

[گردش‌کار محدود](../../.github/workflows/finance-release-candidate.yml) با مجوز فقط خواندن مخزن، checkout بدون credential پایدار، SHA محصول ثابت و actionهای pin‌شده کار می‌کند. هیچ secret، حساب تولید، cPanel، شبکهٔ بانکی یا عملیات انتشار در آن وجود ندارد. سازنده از کتابخانهٔ استاندارد Python استفاده می‌کند؛ Composer، Node یا وابستگی تازه نصب نمی‌کند.

سه خروجی artifact:

- `finance-funding-20261102-source.zip`: فقط ۲۶ فایل allowlist و `candidate-manifest.json`.
- `candidate-manifest.json`: SHA-256 بایت منبع، اندازه، نگاشت ۲۸ مقصد، migrationها و وابستگی‌های مشترک برای تطبیق جداگانه. وابستگی‌های مشترک در ZIP نیستند و خودکار نصب نمی‌شوند.
- `SHA256SUMS`: هش مستقل ZIP و manifest.

وجود artifact به معنی انتشار نیست. `production_state=not_observed` و تمام `expected_before_sha256`ها صریحاً null هستند؛ هش فعلی، backup و وضعیت هر مقصد باید از محیط واقعی خوانده و manifest نصب جدا تکمیل شود. Git blob SHA با SHA-256 محتوا برابر نیست.

سازنده، تطبیق HEAD ثابت، بایت فایل با Git همان commit، محدوده و یکتایی مسیرها، ۲۶/۲۸ مقصد، نبود symlink و محتوای ZIP نهایی را کنترل می‌کند. CI دوباره بسته را می‌سازد و برابری بایتی را می‌سنجد؛ رد تغییر فایل منبع و مسیر خارج محدوده هم واقعاً اجرا می‌شود. آرشیو شامل .env، راز، اطلاعات حساب واقعی، fixture، vendor، cache یا اسکریپت اجرایی تولید نیست.

## گام باقی‌ماندهٔ انتشار

دسترسی اجرایی همین گفتگو و origin مرورگر در زمان آماده‌سازی فراهم نشد؛ این محدودیت اثبات نامعتبر بودن توکن cPanel یا قطع اتصال Chrome در گفتگوهای دیگر نیست. توکن در مخزن، artifact یا CI نگهداری نمی‌شود. راه‌انداز محلی نیز پیش از اجرای دستور شکست خورد؛ این خطا وابستگی پروژه به دیسک دیگری نیست.

پس از فراهم‌شدن کانال معتبر، [قرارداد انتشار](DEPLOYMENT.md) اعمال می‌شود: خواندن اختلاف‌های فعلی و حساب‌های موجود، قفل انتشار، backup خصوصی پایگاه/فایل، هش پیش‌شرط و تطبیق تغییر هم‌زمان؛ سپس فقط دو migration برنامه‌ریزی‌شده پیش از کد وابسته، با APP_KEY موجود. فعال‌سازی محدود سه Blade، کنترل هش مقصدها، دو نسخهٔ CSS و وابستگی‌های مشترک لازم است. تولید می‌تواند با منبع Git تفاوت داشته باشد؛ این بسته اجازهٔ overwrite اختلاف‌ها نیست.

حساب رسالت و واکیف با نوع partner، ارزهای صریح و partner_key مشترک شخص ثبت یا با شناسهٔ رکورد موجود ویرایش می‌شوند. پیش از ایجاد حساب لیر، رکورد احتمالی قبلی بررسی می‌شود. بانک ملت شرکت همان bank مستقل می‌ماند. ثبت هویت حساب، سند افتتاحیه، ماندهٔ ساختگی یا انتقال پول ایجاد نمی‌کند. شماره‌ها فقط در مسیر خصوصی مجاز وارد می‌شوند؛ رسید عمومی فقط وضعیت و شناسهٔ پوشیده را ثبت می‌کند.

برای پذیرش، پروندهٔ واقعی عودت، پرداخت، کرون و سفارش تأمین‌کننده اجرا نمی‌شود. پس از ذخیرهٔ دادهٔ هویت/گردش مالی، حذف ستون یا برگشت کور backend مناسب نیست؛ بازگشت فایل با backup همان انتشار و بررسی سازگاری داده انجام می‌شود. انتشار کد این ابزار برای rollback تولید کاری انجام نمی‌دهد.
