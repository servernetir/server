## آزمون و بازبینی

- **۸۶ تست PHP و ۵۵۷ بررسی موفق**، به‌اضافهٔ **۵ تست JavaScript موفق**؛ CI و بازبینی مستقل نیز موفق بودند.
- آزمون مرجع predicate قبلی، خروجی هم‌ارز ایمیج‌ها را با provider/منطقه، منابع و معماری متفاوت، prefix خالی/نامعمول، مرز Windows و تغییر گارد دسترسی جاری می‌سنجد. شمارندهٔ attribute نشان می‌دهد ورودی‌های ثابت پلن در هر اجرای imageSet یک بار خوانده می‌شوند.
- مقایسهٔ مستقل prune و حفظ شناسه/ترتیب ردیف‌ها، aliasها، قراردادها و عدم دخالت در نرخ/ظرفیت پوشش داده شدند. رابط جدول شامل راهنمای اسکرول و تمرکز کیبورد است؛ فونت، پرچم‌ها، همهٔ ردیف‌ها و لینک‌های خرید در بسته حفظ شده‌اند و پذیرش مرورگر زنده جداگانه ثبت می‌شود.
- چهار تست منتخب قدیمی `CloudPublicPageTest` به‌علت نبود fixture قرارداد جاری نوسان با controller مبنا نیز همان شکست را داشتند. این شکست‌ها ناشی از تغییر جدید نیستند و سبزبودن کل تست‌های پروژه ادعا نمی‌شود.

## انتشار محدود و بازگشت

[manifest بدون راز](cloud-catalog-cpu-20261028/manifest.json) نسخهٔ پیش/پس و مقصد همان چهار فایل را ثبت می‌کند. نصب از روی نسخهٔ جاری و با hash guard انجام شد؛ فایل‌های دارای اختلاف معتبر تولید، به نسخهٔ خام checkout برگردانده نشدند. پشتیبان خصوصی پیش از نصب نگه‌داری شده است. rollback فقط همان چهار فایل را با کنترل hash نسخهٔ نصب‌شده و نبود تغییر جدیدتر برمی‌گرداند؛ هیچ مجوزی برای rollback عمومی اپ، دیتابیس، مالی، حساب، VM یا شبکه ایجاد نمی‌کند.
