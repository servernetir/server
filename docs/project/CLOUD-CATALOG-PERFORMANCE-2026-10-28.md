نسخهٔ پشتیبان و manifest انتشار در همان محدودهٔ خصوصی نگه‌داری می‌شوند؛ اطلاعات دسترسی و دادهٔ مشتری وارد این گزارش نمی‌شوند. طرح rollback فقط همین **سه فایل** را دربرمی‌گیرد، با کنترل hash نسخهٔ نصب‌شده و حفظ هر تغییر جدیدتر. rollback کاتالوگ هیچ عملیات مالی، دیتابیس، حساب، VM، شبکه یا پاک‌سازی عمومی cache را مجاز نمی‌کند.
