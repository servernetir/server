- متن‌ها و۳۵توضیح مستقل در `website/lang/{fa,en,tr}/identity_product.php`؛ کلیدهای هر سه زبان برابرند. دادهٔ JS با `Js::from` و متن‌های HTML با escape عادی Blade منتقل می‌شوند؛ جست‌وجو فقط DOM موجود را فیلتر می‌کند. فارسی/عربیِ ی/ک و بزرگی حروف محلی پشتیبانی می‌شود.
- قیمت/وضعیت/ورودی از `Catalog::publicList()` موجود می‌آیند؛ نرخ مالی ثابت یا صفرِ جایگزین خطا اضافه نشده است. کارت‌ها پیش از مالیات‌اند و مبلغ نهایی فقط در خرید تعیین می‌شود. کدها و نمونهٔ رسید صرفاً نمایشی، LTR و دارای اسکرول داخلی‌اند؛ هیچ fetch تبلیغاتی یا اجرای واقعی وجود ندارد.
- CSS کاملاً به `.ip` محدود است؛ style/nav مشترک مستندات/شرایط و layout اصلی بازطراحی نشدند. کنترل تم همان کنترل موجود است. Tabها دارای Arrow/Home/End، FAQ و جزئیات دارای کنترل native کیبورد، شمارنده/copy دارای live region، focus واضح و reduced-motion رعایت شده‌اند. بدون JS کل کاتالوگ و جزئیات native خوانا باقی می‌ماند.
- backend، قرارداد API، قیمت‌گذاری، کیف پول، KYC/مجوز، روش فعال‌سازی، پنل‌ها، `.env`، vendor، schema و cron این انتشار تغییر نکردند. [سیاست کیف پول بدون سقف مشتری](IDENTITY-API-WALLET-POLICY-2026-10-18.md) برقرار است.

## پذیرش

PHP8.4.26، Laravel و SQLite ایزوله، بدون راز/دیتابیس تولید: `IdentityApiTest|IdentityProductPageTest`، ۷۸تست/۷۰۹assertion موفق؛ تست ارائهٔ فعال با دو تعرفهٔ مصنوعی و حالت همه‌غیرفعال، سه زبان، عدم افشای قیمت عمده/نام تأمین‌کننده و حفظ نرخ خالص را می‌سنجد. این fixture فقط در محیط آزمایش است و وضعیت فروش زنده را نشان نمی‌دهد. بررسی مجدد دو تست صفحه با `short_open_tag=1` و پس از اصلاح CSS، ۲تست/۶۵assertion موفق. JavaScript رندرشدهٔ هر سه زبان با Node `--check` تجزیه شد؛ فایل Blade/inline مصرف می‌شود و خروجی Vite یا وابستگی جدیدی برای build ندارد.

مرورگر واقعی روی پیش‌نمایش و سپس تولید: ۱۸ترکیب fa/en/tr ×۳۹۰/۷۶۸/۱۴۴۰ ×روشن/تیره؛ بدون سرریز افقی، تصویر خراب، کلید ترجمهٔ خام و با یک H1. جست‌وجوی فارسی، نرمال‌سازی «كارت»، انگلیسی mobile و ترکی KİMLİK، دستهٔ بدون خدمت فعال، نمایش۳۵خدمت/۱۳بانکی/۱۳خدماتی، نتیجهٔ خالی، جزئیات mobile/national_code، تب‌های کد و کیبورد، کپی موفق و FAQ بررسی شدند. در تولید خطای console ثبت‌شده صفر؛ reduced-motion عملاً animation:none و scroll:auto داد. مسیر محصول/راهنما/شرایط هر سه زبان HTTP200، هدر واقعی `available_wallet_v1` و۳۵کارت صحیح بود. حالت شکست clipboard به‌طور مستقل تحمیل نشد؛ بازخورد خطا در پیاده‌سازی موجود است. آزمون screen reader و مرورگرهای غیرChromium انجام نشده‌اند.

در بازبینی تصویری، برچسب بررسی و نام API در اندازهٔ کوچک زیر کارت نتیجه می‌افتادند؛ دو اصلاح محدود CSS منتشر شد. پس از اصلاح نهایی، فاصلهٔ bounding box برند تا نتیجه در هر سه زبان در۳۹۰/۷۶۸/۱۴۴۰ به‌ترتیب۶/۹/۱۵px و مثبت است. تصاویر نهایی واقعی سایت، با حذف صرفاً سربرگ حساب از قاب عکس: [دسکتاپ](identity-api-20261018/product-desktop.png) و [موبایل](identity-api-20261018/product-mobile.png). تصویرها تولیدشده با ابزار طراحی یا دادهٔ فروش ساختگی نیستند.

VM/guest، route/NAT/firewall/DNS، proxy/worker، cron و state عامل‌های country-routing/port-forward ثابت‌اند. ماندگاری طراحی در منابع نصب‌شده است. بازگشت: ابتدا style اصلاح layout با guard هش به backup همان انتشار، سپس style اصلاح polish، سپس فقط۱۱مسیر اولیه با manifest و منبع خصوصی پیشین؛ فایل جدید فقط پس از کنترل نبود وابستگی جدیدتر برداشته شود. هیچ restore دیتابیس یا برگشت سیاست کیف پول لازم نیست. فعال‌کردن فروش، تمدید شاهد یا تغییر تعرفه بخشی از rollback ظاهری نیست.
