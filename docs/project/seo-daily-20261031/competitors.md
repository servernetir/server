# مرور محدود رقبا — ۳۱ اکتبر ۲۰۲۶

زمان مشاهده: ۲۰۲۶-۱۰-۳۱، تا ۰۶:۳۶ UTC. دامنه: سه نیت تجاری «سرور مجازی ساعتی»، «اجاره gpu» و «خرید API هوش مصنوعی». AGENTS، NETWORK-CURRENT، مبنای رشد ۱۰ اکتبر و آخرین گزارش روزانهٔ ۳۰ اکتبر خوانده شدند. این مرور جای crawl کامل، Search Console یا آزمون خرید را نمی‌گیرد.

## روش و محدودیت

عبارت‌های بالا با ابزار جست‌وجوی وب جست‌وجو شدند؛ برای تکمیل مقایسه، «خرید API هوش مصنوعی قیمت» و «اجاره gpu حافظه» نیز بررسی شدند. دامنه‌های زیر واقعاً در خروجی این جست‌وجوها دیده شدند؛ فهرست از حافظه یا گزارش قبلی انتخاب نشده است. ترتیب خروجی این ابزار، رتبهٔ قطعی Google در ایران یا دستگاه مشخص نیست و جایگاه عددی ادعا نمی‌شود. اطلاعات صفحه‌های رقبا، گفتهٔ خود عرضه‌کننده است؛ صحت ظرفیت، قیمت یا کیفیت عملی آنها آزمایش نشده است. متن تبلیغاتی و وعدهٔ تجاری آنها به سرورنت منتقل نشد.

صفحه‌های اصلی با ابزار وب خوانده شدند؛ تاریخ crawl نمایش‌داده‌شده برای بعضی نتیجه‌ها قدیمی‌تر از امروز است. برای دو شکاف پیشنهادی، سه GET عمومی مستقیم و بدون حساب نیز انجام شد: `/ai`، یک مدل نمونه و `/gpu`. از دادهٔ حساب، سفارش، API هزینه‌دار، پیام خارجی یا تغییر تولید استفاده نشد. بازکردن دوبارهٔ صفحهٔ آریانت در ابزار وب یک بار timeout داد؛ مشاهدهٔ نخست و snippet موجود بود، اما پذیرش زندهٔ کامل آن ادعا نمی‌شود. ابزار وب صفحهٔ مدل نمونه را نیز باز نکرد؛ GET عمومی مستقل آن HTTP 200 داشت.

## فقط دو بهبود مشخص پیشنهادی

### ۱. انتخاب GPU بر اساس برنامهٔ سازگار

GET مستقیم `/gpu` برابر HTTP 200 بود و ۵۴ radio انتخاب پلن داشت؛ جست‌وجوی نام موجود است. در منبع فعلی `website/resources/views/pages/gpu.blade.php:230` و `:447` تنها فیلتر نام دیده می‌شود. کاربری که نام کارت مناسب را نمی‌داند باید ده‌ها گزینه را مرور کند. پیشنهاد: یک فیلتر اختیاریِ برنامهٔ سازگار از همان `CFG.apps` فعلی، همراه تعداد نتیجه و بازنشانی، بدون تغییر انتخاب خودکار، قیمت یا صلاحیت سفارش. تمام کارت‌ها در HTML اولیه و حالت بدون JavaScript باقی بمانند؛ انتخاب پنهان‌شده نیز بی‌صدا عوض نشود.

دامنهٔ کمینه: همان view، کلیدهای متن سه زبان و تست رفتار مرورگر ساختگی؛ الگوریتم offer و مالی ثابت. معیار پذیرش: ترکیب جست‌وجو و برنامه، صفر نتیجه/بازنشانی، حفظ انتخاب و نرخ، کار با صفحه‌کلید، RTL/LTR و نمایش تمام کارت‌ها بدون JS. فیلتر VRAM فعلاً توصیهٔ اجرایی نیست: هرچند ستون `gpu_vram_mb` وجود دارد، `SaladOperations.php:501` آن را null می‌نویسد؛ نباید حافظه را از نام کارت حدس زد یا وعدهٔ اجرای مدل ساخت.

### ۲. لینک مستقیم به برآورد هزینهٔ موجود مدل AI

GET `/ai` HTTP 200 بود و لینکی به `#usage-planner` نداشت. GET [مدل نمونه](https://servernet.cloud/ai/models/di-xiaomimimomimo-v26-pro-14810b5543) نیز HTTP 200 داشت و `id="usage-planner"` و فرم `data-ai-estimator` حاضر بودند، اما لینک پرش به آن نبود. در منبع، estimator از قبل در `pages/ai/estimator.blade.php:1` با شرط token operation و quote موجود رندر می‌شود؛ `pages/ai/card.blade.php:18` و فهرست پرش `pages/ai/model.blade.php:31` آن را معرفی نمی‌کنند.

پیشنهاد: لینک متنیِ مشروطِ «برآورد هزینهٔ این مدل» از کارت به همان مدل و `#usage-planner`، و لینک پرش داخل صفحهٔ مدل با دقیقاً همان شرط وجود بخش. ماشین‌حساب، رقم، واحد، نرخ، تخفیف، مالیات و سیاست تسویه تازه‌ای ساخته نشود. این کار مزیت فعلی را قابل کشف می‌کند. دامنه: دو view و متن سه زبان؛ تست مدل token با quote، بدون quote، عملیات غیرتوکنی، مقصد anchor و زبان‌ها. لینک عمومی باید بدون JS کار کند و هیچ endpoint خرید اجرا نشود.

اینها توصیهٔ قابل آزمون برای کاربر و ارتباط داخلی‌اند؛ افزایش کلیک، تبدیل یا رتبه از آنها هنوز اندازه‌گیری نشده و تضمین نمی‌شود. در زمان تهیهٔ این فایل، هیچ‌یک توسط این بازبین پیاده‌سازی یا منتشر نشد. اولویت سنجش خرید واقعی GA4 و علت LCP، طبق گزارش ۳۰ اکتبر، با صرف مشاهدهٔ loader یا مرور رقبا بسته نمی‌شود.
