## ممیزی تمام صفحات

در snapshot تولید **۵۵۴ مدل ثبت‌شده** بود. هر مدل در سه زبان، از **HTTP kernel واقعی Laravel تولید در CLI خصوصی** قبل و پس از تغییر رندر شد: **۱۶۶۲ صفحه، همه با پاسخ۲۰۰ در ممیزی نهایی**.

- ۱۱۵۲ صفحه از ۳۸۴ مدل، مطابق سیاست موجود قابل ایندکس و ۵۱۰ صفحه از ۱۷۰ مدل خارج از آن بودند. noindex بازنشسته‌ها/حذف‌شده‌ها حفظ شد؛ این آمار وضعیت Google Index نیست.
- شمار H1، canonical صفحات مجاز، چهار alternate، JSON-LD و noindex بر اساس سیاست بررسی شد؛ صفر مغایرت با این معیارها.
- عنوان تکراری در مدل‌های قابل ایندکس هر زبان در baseline پیدا نشد. سه عنوان بیش از۹۰نویسه متعلق به یک مدل در سه زبان بودند؛ طول عنوان به‌تنهایی خطای فنی نیست.
- FAQPage با پاسخ‌های قابل مشاهدهٔ صفحه منطبق است؛ تست برابری پاسخ‌ها را بررسی می‌کند. Rich result تضمین نشده است.
- description اصلی کاتالوگ به‌صورت متن امن و با برچسب زبان انگلیسی نمایش داده می‌شود؛ script/style، URL خام و الگوی credential منتشر نمی‌شوند. **۱۵۶ مدل قابل ایندکس شرح اصلی نداشتند**؛ برای آن‌ها مشخصات واقعی، راهنمای کاربرد/ارزیابی، محدودیت و نمونهٔ اختصاصی ارائه شد، نه ادعای کیفی ساختگی.
- [ممیزی نهایی تمام مدل‌ها](ai-model-workspace-2026-10-25/model-page-audit.json) و [baseline](ai-model-workspace-2026-10-25/baseline-page-audit.json). ابزار تکرارپذیر در website/scripts/audit-ai-pages.php است؛ فقط CLI، با مسیر اپ و خروجی خصوصی صریح.

## محتوا، مقایسه و محاسبه‌گر

قیمت از AiAvailability/AiPricing، محدودیت از رجیستری و قرارداد رسانه از AiNative خوانده می‌شود. قیمت غایب صفر/رایگان نیست؛ واحد مصرف متفاوت هشدار دارد و قابلیت ثبت‌نشده پشتیبانی قطعی معرفی نمی‌شود. مدل مرتبط با دسته، سازنده و فاصلهٔ کانتکست انتخاب می‌شود؛ ترتیب، رتبهٔ کیفیت نیست. مقایسهٔ آمادهٔ رسانه task یکسان می‌خواهد.

محاسبه‌گر BigInt، تعرفهٔ بدون کش، گردکردن به بالای هر درخواست و اعتبارسنجی تعداد/توکن دارد. این عدد برای برنامه‌ریزی است؛ موتور تسویه همچنان کف هزینه، مصرف گزارش‌شده و قرارداد واقعی را اعمال می‌کند. برای input-only هزینهٔ خروجی فرضی ساخته نمی‌شود. تعرفه، حاشیه، کیف پول و فرمول تسویه تغییر نکردند.

نمونهٔ قبلی خانه اولین عضو فهرست را برای chat می‌گرفت؛ آن عضو ممکن بود embedding باشد. اکنون شناسهٔ chat واقعاً قابل استفاده از دادهٔ صفحه انتخاب می‌شود. retry خودکار SDK خاموش و Idempotency-Key درخواست تازه مشخص است. مثال‌های هر مدل scope و مسیر درست همان عملیات را دارند.

**۴۹۵ نمونهٔ Python با ast.parse و ۴۹۵ نمونهٔ JavaScript با SourceTextModule، بدون خطای نحوی بررسی شدند.** این کدها اجرا نشدند و درخواست پولی ارسال نشد. نمونه‌های pending نیز به‌عنوان مسیر آمادهٔ اجرا معرفی نمی‌شوند.

مقایسه از خانه، منوی AI، کاتالوگ و مدل‌ها لینک دارد. مسیر پایه در سه زبان وارد sitemap و llms.txt شد. انتخاب سفارشی و جستجو noindex هستند تا ترکیب‌های نامحدود صفحهٔ سئویی نسازند. layout موجود برای noindex canonical/hreflang نمی‌فرستد و og:url مرجع را حفظ می‌کند.

فعال‌سازی اولیه PHP8.4.27/fpm-fcgi، invalidate شانزده فایل و حذف شش compiled view موجود از نه منبع هدف بود. route cache وجود نداشت؛ config/cache/view سراسری پاک نشدند. نسل PageCache برای انتشار و اصلاح view تازه شد. V4 فقط CSS بود و متن آن مستقیم در view خوانده می‌شود؛ OPcache ندارد.

کلید موقت خودمان deauthorize، فایل عمومی/خصوصی آن حذف و نبود کلید خودمان در authorized_keys تأیید شد. در پایان یک خط کلید عمومی baseline دیگر حاضر نبود؛ منشأ اختلاف از این بررسی تعیین نشد و آن کلید بازنویسی/بازفعال نشد. کلید دیگری عمداً ویرایش نشد. هر سه gateway یک‌بارمصرف POST با هدر محرمانه خودحذف و غیبتشان تأیید شد؛ راز در URL یا اسناد نیست.

rollback.py اصلی باید همهٔ هش‌های مقصد را با after نهایی و backupها را با before کنترل کند و روی اختلاف متوقف شود. فقط همین۱۸ فایل بازگردند؛ فایل جدید تنها با تطبیق after حذف شود. PHPهای تغییرکرده در pool وب invalidate، compiled viewهای همین منابع تازه و نسل PageCache افزایش یابد. فعال‌ساز دارای receipt کورکورانه تکرار نشود؛ فعال‌سازی بازگشت باید با نسخهٔ برگشته تطبیق یابد. سه زبان، مقایسه و یک مدل از هر عملیات دوباره پذیرفته شوند. rollback اجرا نشده است.

migration، روابط مدل، تعرفه/حاشیه، پول مشتری، قرارداد اجرای API، cron، VM/guest، SMTP، route، NAT/firewall، DNS، proxy و state عامل‌های کشور/پورت تغییر نکردند. ممیزی، view و cacheهای طبیعی درخواست را به کار گرفت؛ شمار مدل‌های رجیستری به معنی «همه آمادهٔ فروش» نیست.
