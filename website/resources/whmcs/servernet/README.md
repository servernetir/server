# ماژول نمایندگی دامنهٔ سرورنت برای WHMCS

نسخهٔ ۱٫۰٫۰ · سازگار با WHMCS 8.0+ و PHP 8.1+

با این ماژول، WHMCS شما دامنه‌ها را مستقیم از حساب نمایندگی سرورنت ثبت و
تمدید می‌کند: بدون ورود دستی، بدون کپی‌کردن اطلاعات، با قیمت سطح نمایندگی
خودتان.

---

## ۱) پیش‌نیازها

| | |
|---|---|
| حساب نمایندگی فعال | از پشتیبانی سرورنت بخواهید حسابتان را به‌عنوان نمایندهٔ دامنه فعال کند |
| اعتبار حساب | ثبت و تمدید **از اعتبار کسر می‌شود**؛ حساب خالی یعنی سفارش ناموفق |
| ارز WHMCS | باید **تومان (IRT)** باشد — قیمت‌ها تومانی برمی‌گردند |
| مشخصات مالک | نام، نشانی، شهر، کدپستی و تلفن در پروفایل سرورنت کامل باشد |

---

## ۲) ساختن توکن

۱. وارد پنل کاربری سرورنت شوید → **امنیت** → **توکن API**
۲. توکن تازه بسازید و این دسترسی‌ها را بدهید:
   - `domains:write` — ثبت و تمدید
   - `domains:manage` — تغییر نام‌سرور و قفل
۳. **IP سرور WHMCS خود را در فهرست مجاز توکن بگذارید.**
   این مهم‌ترین محافظ شماست: اگر روزی سرورتان نفوذ شود، توکن بیرون از آن IP
   کار نمی‌کند.
۴. توکن فقط **یک بار** نشان داده می‌شود. همان‌جا کپی‌اش کنید.

---

## ۳) نصب

```
modules/registrars/servernet/
├── servernet.php
├── lib/ServerNetApi.php
└── README.md
```

سپس در WHMCS:

**Configuration → System Settings → Domain Registrars → ServerNet**

- **توکن API:** همان رشته‌ای که ساختید
- **نشانی API:** دست نزنید
- **نام‌سرورهای پیش‌فرض:** خالی بگذارید تا نام‌سرورهای سرورنت استفاده شود

روی **Test Connection** بزنید. اگر پیام موفقیت دیدید، آماده‌اید.

> آزمون اتصال فقط اتصال را بررسی نمی‌کند: اگر توکن دسترسی `domains:write`
> نداشته باشد یا حسابتان هنوز نماینده نشده باشد، همان‌جا می‌گوید — نه وسط
> سفارش یک مشتری واقعی.

---

## ۴) وارد کردن قیمت‌ها

**Configuration → System Settings → Domain Pricing → Import from Registrar**

قیمت‌های وارد‌شده **قیمت خرید شما** هستند (با تخفیف سطحتان). سود خودتان را
روی همین‌ها اضافه کنید.

⚠️ قیمت ثبت و تمدید در بسیاری از پسوندها بسیار متفاوت است — مثلاً `.shop`
که تمدیدش چند برابر ثبت سال اول است. ماژول هر سه قیمت را جدا وارد می‌کند؛
**قیمت فروش تمدید را برابر ثبت نگذارید**، وگرنه هر تمدید با ضرر می‌فروشید.

---

## ۵) چه کارهایی از WHMCS انجام می‌شود و چه کارهایی نه

| کار | از WHMCS | توضیح |
|---|---|---|
| بررسی موجودی دامنه | ✅ | |
| ثبت دامنه | ✅ | از اعتبار کسر می‌شود |
| تمدید | ✅ | |
| تغییر نام‌سرور | ✅ | حداقل دو نام‌سرور |
| **روشن** کردن قفل انتقال | ✅ | |
| همگام‌سازی وضعیت و انقضا | ✅ | خودکار |
| **خاموش** کردن قفل انتقال | ❌ | فقط از پنل سرورنت |
| دریافت کد انتقال (EPP) | ❌ | فقط از پنل سرورنت |
| ویرایش مشخصات مالک | ❌ | مالک ثبت‌شده، حساب نمایندگی شماست |
| انتقال دامنه به سرورنت | ❌ | نسخهٔ بعد |

**چرا این چهارتا نیست:** سه‌تای اول با یک توکن لورفته می‌توانند دامنهٔ
مشتریان شما را **بربایند**، نه اینکه فقط پول خرج کنند. قفل باز و کد EPP
با هم یعنی هر کسی می‌تواند دامنه را ببرد. این‌ها را عمداً پشت ورود انسانی
به پنل نگه داشته‌ایم.

---

## ۶) نکته‌های مهم

**سفارش «در حال انجام» شکست نیست.** گاهی ثبت چند دقیقه طول می‌کشد. ماژول در
این حالت خطا نمی‌دهد؛ همگام‌سازی خودکار WHMCS وضعیت واقعی را می‌آورد.

**اگر ارتباط قطع شد، دوباره سفارش ندهید.** پیام «نتیجه نامعلوم است» یعنی
ممکن است دامنه ثبت شده باشد. اول در پنل سرورنت نگاه کنید.

**تلاش دوبارهٔ WHMCS دامنهٔ دوم نمی‌خرد.** هر درخواست یک کلید یکتا دارد؛
درخواست تکراری همان پاسخ قبلی را می‌گیرد، نه یک خرید تازه.

**پسوندهای ایرانی (`.ir` و خانواده‌اش) از این مسیر فروخته نمی‌شوند.** قیمت
آنها از رجیسترار اروپایی چند ده برابر قیمت واقعی ایرنیک است و نشان‌دادنش به
مشتری بی‌معناست. برای `.ir` فعلاً از مسیر مستقیم ایرنیک استفاده کنید.

## ۷) عیب‌یابی

لاگ هر تماس در **Utilities → Logs → Module Log** است (اول باید فعالش کنید).

| پیام | یعنی |
|---|---|
| `insufficient_credit` | اعتبار حساب نمایندگی کافی نیست |
| `insufficient_scope` | توکن دسترسی `domains:write` ندارد |
| `ip_not_allowed` | IP این سرور در فهرست مجاز توکن نیست |
| `token_expired` / `token_revoked` | توکن تازه بسازید |
| `daily_cap_reached` | سقف خرج روزانه پر شده |
| `registrant_incomplete` | پروفایل مالک در پنل سرورنت ناقص است |
| `tld_blocked` | ثبت آن پسوند موقتاً از سمت ما مقدور نیست؛ مبلغی کسر نشده |

مستندات کامل API: <https://servernet.cloud/developers>

## ۸) وضعیت آزمون

⚠️ صادقانه: منطق ارتباط با API (`lib/ServerNetApi.php`) تست خودکار دارد، ولی
خودِ لایهٔ WHMCS (`servernet.php`) روی یک نصب واقعی WHMCS آزموده نشده است.
پیش از استفاده روی سایت زنده، **یک بار روی نصب آزمایشی امتحانش کنید** و
نتیجه را به ما بگویید.
