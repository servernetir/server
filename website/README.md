# اپلیکیشن ServerNet

این پوشه ریشهٔ اپ فعال **servernet.cloud** و پنل **console.servernet.cloud** است؛ با `app/` قدیمی در ریشهٔ مخزن اشتباه نشود.

مرجع توسعه و تحویل کد **`develop`** است.

| موضوع | سند |
|---|---|
| نقشهٔ پروژه و اجزای بیرون از سایت | [نمایهٔ پروژه](../docs/project/README.md) |
| نصب محلی، تست و قراردادهای کد | [ONBOARDING](docs/ONBOARDING.md) |
| نرخ ارز نوسان و قیمت‌گذاری محصولات | [راهنمای قیمت‌گذاری نوسان](docs/pricing/navasan.md) |
| همکاری و بازبینی | [TEAM](../docs/project/TEAM.md) |
| انتشار و بازگشت cPanel | [DEPLOYMENT](../docs/project/DEPLOYMENT.md) |
| تله‌ها و تاریخچهٔ فنی | [CLAUDE.md](CLAUDE.md) |

PHP `^8.3` و Laravel `^13.8` محدودیت‌های `composer.json` هستند، نه گواه نسخهٔ نصب‌شدهٔ تولید. تست‌ها SQLite درون‌حافظه‌ای دارند؛ MariaDB تولید در راهنمای فنی گزارش شده است.

**کل این پوشه را در `public_html` آپلود نکنید.** چیدمان فعلی اپ خارج از webroot است؛ فایل‌های محیط، storage زنده و `index.php` ویژهٔ سرور باید حفظ شوند. جزئیات و استثناها در راهنمای دیپلوی آمده است.

این README جای متن نمونهٔ Laravel را برای ورود به پروژه گرفته است. مجوز و انتساب هر وابستگی مستقل از راهنمای سرورنت است؛ از متن نمونهٔ قبلی نباید مجوز حقوقی کل محصول را استنتاج کرد.
