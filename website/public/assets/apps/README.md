# Application logo assets

Self-hosted brand marks identify software offered in the application catalog. Third-party names and marks remain the property of their respective owners; this is not an endorsement claim.

See `sources.json` for per-family provenance. Dashboard Icons is pinned to commit `6d31345986eba2067a63eb41c1a5a87d4e8e850a`; Simple Icons is pinned to `16.35.0`. Their collection licenses are included. Project-specific marks use the official project repositories or website assets recorded in the manifest.

The SVGs have a consistent badge canvas. LAMP and LEMP use a composition of their Linux, Apache/NGINX, MySQL and PHP components rather than an unrelated application's mark. Four official raster marks are embedded locally inside SVG wrappers. Assets contain no scripts or external image requests. New catalog families need a matching asset and an entry in `CloudImage::APP_LOGOS`; unknown families retain the existing fallback.
